# Course authoring sources

The new bilingual courses use the existing `ppts/kit` layouts. Their lesson YAML files are maintained beside their built decks. The curriculum specifications in this folder generate the initial editions. Subsequent teaching revisions belong in the lesson YAML files.

The source proposals remain available for comparison. Current software, store policies and legal rules belong in dated annexes with official source links. Synthetic cases and numerical examples are identified in the lesson notes.
