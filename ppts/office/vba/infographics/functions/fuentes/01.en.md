# A VBA Function turns inputs into a result

A Function returns a value that another procedure or a worksheet formula can use.

## Define the calculation

Place this code in a standard module. Option Explicit belongs at the top of the module.

```vb
Option Explicit

Public Function WithTax( _
    ByVal price As Double, _
    ByVal rate As Double) As Double
    WithTax = price * (1 + rate)
End Function
```

The function name is WithTax. price and rate are inputs. ByVal passes a copy of each numeric argument. The final As Double declares the result type. Assigning to WithTax sets the return value. End Function closes the procedure. A space followed by `_` continues a statement on the next line.

## Follow the value

Inputs: price = 100 and rate = 0.08. Calculation: 100 * (1 + 0.08). Result: 108. The rate 0.08 represents 8%.

## Call it from VBA

```vb
Sub Demo()
    Dim total As Double
    total = WithTax(100, 0.08)
    Debug.Print total
End Sub
```

The Immediate window displays 108. The parentheses pass arguments to the function. The result is stored in total.

## Call it from a cell

Enter 100 in A2 and 0.08 in B2. In C2, enter:

```excel
=WithTax(A2,B2)
```

C2 returns 108. This is a user-defined function (UDF). Cell formula separators depend on your regional settings.

## Choose the procedure

| Procedure | Typical purpose | How to use it |
| --- | --- | --- |
| Function | Calculate and return a value | Use its result in an expression. |
| Sub | Perform actions | Run a macro, write cells, or show a message. |

A function called from a worksheet cell should calculate its result without changing other cells.

## Set it up

In desktop Excel, open Developer > Visual Basic. Select the workbook project, then Insert > Module. Paste the code and save the workbook as .xlsm. Macros must be allowed for this trusted workbook. VBA does not run in Excel for the web.
