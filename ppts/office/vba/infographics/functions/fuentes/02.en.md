# Call Excel functions directly from VBA

WorksheetFunction calculates a result in your code. Range.Formula stores a formula in a cell.

## Calculate a result now

Use a worksheet named Data in the workbook that contains the code. Enter 10, 20, 30, and 40 in B2:B5.

```vb
Sub Summarize()
    Dim ws As Worksheet
    Dim data As Range
    Dim total As Double
    Set ws = ThisWorkbook.Worksheets("Data")
    Set data = ws.Range("B2:B5")
    total = Application.WorksheetFunction _
        .Sum(data)
    ws.Range("D2").Value = total
End Sub
```

B2:B5 contains 10, 20, 30, and 40. Sum returns 100; D2 receives that value. Set assigns an object reference. Passing data supplies a Range object, not the text "B2:B5".

## Reuse the Excel calculation

| Worksheet formula | VBA expression after data is set |
| --- | --- |
| =SUM(B2:B5) | Application.WorksheetFunction.Sum(data) |
| =AVERAGE(B2:B5) | Application.WorksheetFunction.Average(data) |
| =MAX(B2:B5) | Application.WorksheetFunction.Max(data) |

These examples return 100, 25, and 40, respectively. VBA uses English member names and commas between arguments. WorksheetFunction exposes many Excel functions, but not every worksheet function.

## Store a formula for recalculation

After ws is set:

```vb
ws.Range("D3").Formula = "=SUM(B2:B5)"
```

D3 contains a formula and updates when Excel recalculates. D2 contains the value computed when the macro ran. Formula uses English function names; FormulaLocal uses the user's language.

## Handle a missing lookup

Inside a Sub, after ws is set, ids refers to the lookup range. Match with 0 searches for an exact match and returns a relative position.

```vb
Dim ids As Range
Dim hit As Variant
Set ids = ws.Range("A2:A5")
hit = Application.Match("P-02", ids, 0)
If IsError(hit) Then
    MsgBox "Not found"
Else
    MsgBox hit
End If
```

Application.Match can return an Excel error value, so keep hit as Variant and check IsError. WorksheetFunction.Match raises a VBA runtime error when no match exists.

## Keep the function families clear

Len, Left, and CStr are native VBA functions. Call them directly. Excel worksheet functions use Application.WorksheetFunction. A VBA function and an Excel function with similar names can behave differently.
