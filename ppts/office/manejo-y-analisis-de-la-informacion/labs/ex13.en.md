# Exercise 13 · Text functions, date codes and custom number formats

Week 4, sessions 7 and 8, alongside `UPPER`, `LOWER`, `PROPER`, `TEXT`, `DAY`, `MONTH`, `YEAR` and `LEFT`. Sixty students with a birth date each, and two sheets that reach the same three facts by different routes: functions that return a number, `TEXT` that returns a string, and a number format that changes only what the cell displays. Knowing which of the three a task is asking for is most of the objective. Hand in both sheets filled to the last row, plus the four-row fraction block at the bottom of the Text sheet.

**Objectives** MO-200 4.3.1, MO-200 4.3.2, MO-200 4.3.3, MO-200 2.2.6, MO-201 2.2.1

## The data

Sixty students, `024300` to `024359`, born between 1 January 2000 and 14 December 2001. Too many rows to retype, so the input columns are in CSV and the answer columns are left out.

### Sheet Text

Headers in row 2, data in `B3:F62`. Columns `G` to `O` are the answer columns and start empty. The names are stored in lower case on purpose, because two of the tasks are about putting the capitals back. Input columns in [`labs/data/ex13-text.csv`](data/ex13-text.csv), 60 rows, 5 columns.

| Column | Header | Holds |
|---|---|---|
| B | ID | Text, six digits with a leading zero |
| C | NAME | Given name, lower case |
| D | FATHER'S LAST NAME | Paternal surname, lower case |
| E | MOTHER'S LAST NAME | Maternal surname, lower case |
| F | DATE OF BIRTH | A real date, displayed as `dd-mmm-yyyy` |

Two things about that ID column. It is text, not a number, and the leading zero is part of the value. When the CSV is imported through **From Text/CSV**, set **Data Type Detection** to **Do not detect data types** or the zero is gone before the first formula is written.

### Sheet Dates

The same sixty students, this time with the names already capitalised, in `B3:F62`. Columns `G` to `O` are the answer columns. Input columns in [`labs/data/ex13-dates.csv`](data/ex13-dates.csv), 60 rows, 5 columns.

### The fraction block, Text sheet rows 67 to 71

Four irrational numbers and five columns of formatting. Column B holds the name, column C is where the value goes, and columns D to G show that same value four different ways.

| Cell | B, NUMBER | C, NUMBER (DECIMAL) |
|---|---|---|
| 68 | Pi | `=PI()` |
| 69 | e | `=EXP(1)` |
| 70 | Root of 2 | `=SQRT(2)` |
| 71 | Root of 3 | `=SQRT(3)` |

## What to do

### Sheet Text, columns G to O

Write each formula once in row 3 and fill down to row 62.

1. `G`, FULL NAME. Join name, paternal surname and maternal surname with `CONCAT`, one space between each pair. `CONCAT` takes a range in one box, so `=CONCAT(C3," ",D3," ",E3)` is written as five arguments rather than one drag.
2. `H`, FULL NAME (Uppercase). `UPPER` over the cell you just built in G.
3. `I`, FULL NAME (Proper). `PROPER` over the same cell. Note what `PROPER` does to `de santa ana` and `cabeza de vaca`: it capitalises every word, particles included, which is not how those surnames are written. The function has no exception list. Say so in the hand-in.
4. `J`, email. The workbook does not say what the address should look like, so use this convention and be consistent: given name, a dot, paternal surname, then `@escuela.edu.mx`, all lower case. `=CONCAT(C3,".",D3,"@escuela.edu.mx")`. Substitute the real domain if the instructor gives one.
5. `K`, DAY OF THE WEEK OF BIRTH. `=TEXT(F3,"dddd")` returns the full name of the weekday.
6. `L`, DAY OF BIRTH (NUMBER). `=TEXT(F3,"dd")` returns two digits as text, so 6 July comes back as `06`, not `6`.
7. `M`, MONTH OF BIRTH. `=TEXT(F3,"mmmm")` returns the full month name.
8. `N`, BIRTHDAY. Build the sentence with `&` rather than a function: `=I3&"'s birthday is on "&L3&" of "&M3`. This is the one task the objective wants done without `CONCAT`, so the two routes sit side by side on the same sheet.
9. `O`, RFC. The first ten characters, built from the pieces you already have: two letters from the paternal surname, one from the maternal surname, one from the given name, then the birth date as six digits. `=UPPER(LEFT(D3,2)&LEFT(E3,1)&LEFT(C3,1)&TEXT(F3,"yymmdd"))`. Two caveats worth writing down. The real rule takes the first letter and the first internal vowel of the paternal surname, which `LEFT` cannot do; and the real rule strips accents, which this formula does not, so `lópez` comes out as `LÓP` instead of `LOP`.

### The fraction block

10. `C68` to `C71`: put the four values in with `=PI()`, `=EXP(1)`, `=SQRT(2)` and `=SQRT(3)`.
11. `D68:D71`: point each cell at its value in column C, then format the range as a fraction with a one-digit denominator, code `?/?`.
12. `E68:E71`: same values, forced to thirds. There is no built-in entry for thirds, so this one goes through the **Custom** category with the code `# ?/3`.
13. `F68:F71`: same values, forced to fifths, code `# ?/5`.
14. `G68:G71`: same values as a mixed fraction, code `# ?/?`.

Formatting is the whole task here. The number in the cell never changes, and the formula bar still shows the full decimal in all five columns.

### Sheet Dates, columns G to O

15. `G`, `H`, `I`: extract the day, the month and the year as numbers, with `=DAY(F3)`, `=MONTH(F3)` and `=YEAR(F3)`. Three functions, three numbers you can do arithmetic with.
16. `J`, `K`, `L`: the same three facts as text, with `=TEXT(F3,"dd")`, `=TEXT(F3,"mmmm")` and `=TEXT(F3,"yyyy")`. Left-aligned by default, because they are strings.
17. `M`, `N`, `O`: the same three facts again, this time by formatting. Put `=F3` in each cell, then give each column its own custom number format: `dd` in M, `mmmm` in N, `yyyy` in O. The value stored is the whole date in all three columns, and only the display differs. Those three cells arrive from the professor's file already carrying `dd mmmm yyyy`, which shows the lot; replacing that code is the task.

Compare G with J with M on any row. Same day of the month, three different things in the cell: a number, a string, and a date wearing a mask.

### The format codes

## Exam routes used here

### MO-200 4.3.3, CONCAT

1. Click the result cell.
2. Go to the **Formulas** tab, **Function Library** group, click **Text**, and click **CONCAT**.
3. In the **Function Arguments** dialog, click in **Text1**. `CONCAT` takes a whole range in one box, so a drag over `C3:E3` is one argument, not three. For this exercise the spaces have to go between the pieces, so use one box per piece instead.
4. Add the literal text in the next box, including its spaces, for example a single space. In the dialog you type the space and the dialog adds the quotation marks.
5. Read **Formula result =** and click **OK**.

**Short route, not graded.** Write `=C3&" "&D3&" "&E3`. It concatenates correctly and it is not a function, so a task worded "use the CONCAT function" fails. The other trap is `CONCATENATE`, the retired predecessor, which still runs and is not what the objective names. Task 8 is the reverse case: it asks for `&` by name, and a `CONCAT` there fails for the same reason.

**Shortcut.** `Shift+F3` opens **Insert Function**.

**How to check it.** Put an empty cell in the middle of the range and compare. `CONCAT` closes the gap with nothing, which is why a name with no maternal surname would come out with a double space if the spaces were typed as separate arguments.

### MO-200 4.3.2, UPPER

1. Click the result cell.
2. Go to the **Formulas** tab, **Function Library** group, and click **Text**.
3. Click **UPPER**. **PROPER** sits in the same list and belongs to a different task on this sheet, so read the name before clicking.
4. In the **Function Arguments** dialog, click in the **Text** box and select the source cell. Both functions take exactly one argument.
5. Read **Formula result =** and click **OK**.
6. Fill down.

**Short route, not graded.** Retype the text in capitals. Retyping breaks the link to the source and hides the trailing spaces the source data actually carries. Two rows in this file have one, `angélica ` in `C22` and `lucía ` in `C26`, and they surface as a double space in column G.

**How to check it.** Point `LEN` at `C22`. A result one higher than the visible characters means a trailing space.

### MO-200 4.3.1, LEFT

1. Click the result cell.
2. Go to the **Formulas** tab, **Function Library** group, click **Text**, and click **LEFT**.
3. The **Function Arguments** dialog shows two boxes. Click in **Text** and select the source cell; click in **Num_chars** and type how many characters to take. Leaving **Num_chars** empty returns one character.
4. Read **Formula result =** at the bottom and click **OK**, then fill down.

**Short route, not graded.** Type the first two or three results by hand and press `Ctrl+E` for Flash Fill. Excel infers the pattern and fills the column. The column is correct and completely static: change a source value and the split does not follow. When the task names the function, Flash Fill scores nothing.

**How to check it.** Edit one surname and confirm the RFC in column O updates. Then read the last row, where surnames of a different length usually expose an off-by-one.

### MO-201 2.2.1, create custom number formats

This is the route for tasks 12 to 14 and for the three date columns on the Dates sheet.

1. Select the cells.
2. Press `Ctrl+1`, or go to the **Home** tab, **Number** group, and click the dialog box launcher. **Format Cells** opens on the **Number** tab.
3. Build the closest match first with a real category. For the fractions, select **Fraction** and pick **Up to one digit (1/4)** from the **Type** list. This step is not decoration: Excel remembers the code it just built.
4. Now select **Custom** at the bottom of the **Category** list. The **Type** box already shows the code from step 3, ready to edit.
5. Edit the code in the **Type** box: `# ?/3` for thirds, `# ?/5` for fifths, `dd` or `mmmm` or `yyyy` for the date columns.
6. Click **OK**.
7. To delete a code you no longer want, reopen `Ctrl+1`, **Custom**, select the code in the **Type** list and click **Delete**. Only custom codes can be deleted; the built-in ones have no Delete button.

![Format Cells, the Number tab](../../../img/en/format-cells-dialog.png)

*The Category list runs from General down to Custom, the entry step 4 asks for. Selecting Fraction first and only then Custom is what leaves the built-in code sitting in the Type box, ready to be edited into `# ?/3`.*

**Short route, not graded.** The **Home** tab, **Number** group buttons: **Increase Decimal**, **Comma Style**, **Percent Style**. Three clicks and the column looks tidy. Those buttons cannot force a denominator and cannot show a date as its month name alone, so the moment the task names either one the ribbon route runs out.

**Shortcut.** `Ctrl+1` opens Format Cells and lands on whichever tab was last used, so press it once to check where you are.

**How to check it.** Select the cell and press `Ctrl+1`. The **Category** list shows **Custom** selected with your code in the **Type** box, and the formula bar shows the original number untouched, which proves you formatted the value rather than retyping it.

## Checks

Row 3 is Jennifer López Pérez, born 6 July 2001. Every column can be read off that one row.

| Column | Header | Row 3 |
|---|---|---|
| G | FULL NAME | `jennifer lópez pérez` |
| H | FULL NAME (Uppercase) | `JENNIFER LÓPEZ PÉREZ` |
| I | FULL NAME (Proper) | `Jennifer López Pérez` |
| J | email | `jennifer.lópez@escuela.edu.mx` |
| K | DAY OF THE WEEK OF BIRTH | `Friday` |
| L | DAY OF BIRTH (NUMBER) | `06` |
| M | MONTH OF BIRTH | `July` |
| N | BIRTHDAY | `Jennifer López Pérez's birthday is on 06 of July` |
| O | RFC | `LÓPJ010706` |

Ten characters, which is what the task asks for, and still not a valid RFC. The real code for this student is `LOPJ010706`: no accent, because the rule strips them, and the second letter happens to match only by luck, since the rule takes the first internal vowel of `LOPEZ` rather than its second letter. Wrap the surname in `SUBSTITUTE` if you want the accent gone, and note in the hand-in that `LEFT` cannot find an internal vowel at all.

On the Dates sheet, the same row must produce:

| Columns | Result | What it is |
|---|---|---|
| G, H, I | 6, 7, 2001 | Numbers, right aligned, usable in arithmetic |
| J, K, L | `06`, `July`, `2001` | Text, left aligned |
| M, N, O | 06, July, 2001 | The whole date in all three, formatted three ways |

Four checks that separate the three routes.

- Click `M3` and read the formula bar. It must show the complete date, 6 July 2001. If it shows only the day, the date was retyped rather than formatted.
- Multiply `G3` by 2. It works and gives 12. Try the same on `J3` and Excel coerces the string, which looks like it works until a day comes back as `06` and a sort puts it in the wrong place.
- Change `F3` to 25 December 2001. Columns G to O on both sheets must all move. Column K must read `Tuesday` and column M must read `December`.
- Select `E68:E71`, press `Ctrl+1`, and confirm the **Category** reads **Custom** with `# ?/3` in the **Type** box. The **Fraction** category has no thirds entry, so a Fraction selection there means the code was never edited.
