# Homework 22 · Subtotals on an order log

The take-home twin of Exercise 22. Two hundred and forty-six clothing orders across thirteen columns, the size where subtotals stop being a novelty and start being faster than anything else.

**Objectives** MO-201 2.2.4

## The data

**clothing orders**, 246 rows and 12 columns. [../data/hw22-clothing-orders.csv](../data/hw22-clothing-orders.csv)
## What to do

- Datos ropa holds order number, date, media, vendor, platform, commission, order type, client type and gender.
- Sorting before subtotalling is not a suggestion. Subtotal inserts a break every time the sort key changes, so an unsorted column produces one subtotal per row.
- The sheet name is Spanish in an otherwise English workbook. It is left alone so the file still matches what the instructor hands out.

## Checks

Before handing it in, confirm the row count of every result against the source, and make sure any sort or filter you applied is either removed or deliberate. Hand in the workbook as `Homework 22 Excel_Your name.xlsx`.
