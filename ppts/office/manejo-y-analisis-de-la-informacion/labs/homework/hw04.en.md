# Homework 4 · Page setup, print area and workbook views

Two order lists that are both too wide and too long to print sensibly, and the whole job is making them printable. Custom date codes, a print area, repeated titles, frozen panes, landscape, page breaks dragged by hand, a header carrying your name, and an export to PDF. It lands in week 17, session 33, the last teaching session of the course, whose led is "preparing a workbook for printing and distribution". Hand in two files: `Homework 4 Excel_Your name.xlsx` with the page break view still showing, and the PDF you generated from it.

**Objectives** MO-200 1.3.1, 1.3.2, 1.3.3, 1.4.2, 1.4.3, 1.5.1, 1.5.2, 2.2.5, 2.2.6, 2.2.7, MO-201 2.2.1

## The data

Two sheets, both too long to sit in a markdown table.

[../data/hw04-fees.csv](../data/hw04-fees.csv), 49 rows, 5 columns. Header on row 1.

| Column | Header | Holds |

## What to do

### Hoja1

1. Apply the cell style **40% - Accent6** to the header row, row 1. Route 2.2.7. The gallery entry sits in the **Themed Cell Styles** block and its Spanish caption is `40% - Énfasis6`.
2. Give column A the custom number format `dd-mmm-yy`. Route 2.2.1 of the Expert list. The serials turn into readable dates, `15-Jan-06` and so on.
3. Put full borders on the whole table, A1:E50. Route 2.2.6, from the **Border** tab, style and colour first.
4. Give column C a currency-style format with two decimal places and no currency symbol. Route 2.2.5: the **Number** category with **Use 1000 Separator (,)** selected and **Decimal places** set to 2 does exactly this, and so does **Accounting** with **Symbol** set to **None**.
5. Autofit the width of every column. Route 1.3.2.
6. Set row 1 to repeat at the top of every printed page. Route 1.3.1, the **Sheet** tab of Page Setup, **Rows to repeat at top:**.
7. Set the print area to A1:E20, so nothing below row 20 prints. Route 1.5.1.

### Hoja2

8. Move the `Product Name` column from column O to column B. Everything from the old B onwards shifts one column right.
9. Freeze the panes so that row 1, column A and column B stay on screen while the rest scrolls. Route 1.4.3. The anchor cell is C2.
10. Set row 1 to repeat at the top of every printed page and columns A and B to repeat at the left of every printed page. Route 1.3.1, **Rows to repeat at top:** and **Columns to repeat at left:** on the **Sheet** tab.
11. Set the orientation to Landscape. Route 1.3.1, **Page** tab.
12. Switch to **Page Break Preview** and drag the page breaks until the whole sheet prints on four pages. Route 1.4.2. Dragging a break turns the dashed automatic line into a solid manual one, which is the visible proof the view was used rather than the scaling box on the Page tab.
13. Put your name in the header of the sheet. Route 1.3.3, **Custom Header...**, and type it into the section the header needs, not into a cell.
14. Export the sheet to PDF. Route 1.5.2.
15. Save the workbook with the page break view still active and upload both files to Moodle.

## Exam routes used here

**1.3.1 Modify page setup.** Select the worksheet, or `Ctrl`-click several sheet tabs to apply the same setup to a group. Go to the **Page Layout** tab, **Page Setup** group, and click the dialog box launcher, the small arrow in the bottom right corner of the group. **Page Setup** opens with four tabs, **Page**, **Margins**, **Header/Footer** and **Sheet**, and everything below happens without closing it. On the **Page** tab set **Orientation** to **Portrait** or **Landscape**, and **Scaling** to **Adjust to: __ % normal size** or **Fit to: __ page(s) wide by __ tall**; set **Paper size:** and **First page number:** here too. On the **Margins** tab set **Top:**, **Bottom:**, **Left:**, **Right:**, the **Header:** and **Footer:** distances, and the **Center on page** check boxes **Horizontally** and **Vertically**. On the **Sheet** tab, under **Print titles**, set **Rows to repeat at top:** and **Columns to repeat at left:** by clicking the collapse arrow and dragging over the row or column headings; under **Print**, tick **Gridlines**, **Black and white**, **Draft quality** and **Row and column headings**; under **Page order**, choose **Down, then over** or **Over, then down**. The **Print area:** box at the top of the Sheet tab is the second route to 1.5.1. Click **Print Preview** inside the dialog to check, then **OK**.

**1.3.2 Adjust row height and column width.** Select the columns by clicking their headings. **Home** tab, **Cells** group, **Format**, then **AutoFit Column Width** to size to content, or **Column Width...** to type a number in characters of the standard font.

**1.3.3 Customize headers and footers.** Open **Page Setup** as above and go to the **Header/Footer** tab. The **Header:** and **Footer:** lists hold canned entries; for anything the task words specifically, ignore them and click **Custom Header...**. The **Header** dialog opens with three boxes, **Left section:**, **Center section:** and **Right section:**. Click into the section the task names and type the literal text. Insert dynamic fields with the buttons above the boxes rather than typing the codes: **Format Text**, **Insert Page Number**, **Insert Number of Pages**, **Insert Date**, **Insert Time**, **Insert File Path**, **Insert File Name**, **Insert Sheet Name**, **Insert Picture**, **Format Picture**. Each writes its code into the box: `&P` page number, `&N` number of pages, `&D` date, `&T` time, `&F` file name, `&A` sheet name. Click **OK** to return to Page Setup, use **Custom Footer...** for the footer, set the four check boxes **Different odd and even pages**, **Different first page**, **Scale with Document** and **Align with page margins**, then **OK**.

**1.4.2 Display and modify workbook content in different views.** Go to the **View** tab, **Workbook Views** group, and click **Normal**, **Page Break Preview** or **Page Layout**. In **Page Break Preview**, drag a blue page-break line to move it; dragging creates a manual break, drawn as a solid line where the automatic break was dashed. Right-click a cell and click **Reset All Page Breaks** to return to automatic breaks. In **Page Layout**, click directly into the header and footer boxes to edit them and drag the rulers to change margins.

**1.4.3 Freeze worksheet rows and columns.** Work out the anchor cell first: Excel freezes everything above and everything to the left of the cell you select, so to freeze row 1 plus columns A and B the anchor is C2. Click that single cell, not the row heading and not the column heading. Go to the **View** tab, **Window** group, click **Freeze Panes**, and click **Freeze Panes** in the drop-down. The two entries below it, **Freeze Top Row** and **Freeze First Column**, ignore the selection and freeze exactly one line each. To release, click **Freeze Panes** again and click **Unfreeze Panes**.

**1.5.1 Set a print area.** Select the range to print; `Ctrl`-click each additional block for a print area in several pieces. Go to the **Page Layout** tab, **Page Setup** group, click **Print Area**, and click **Set Print Area**. To extend an existing one, select the extra range and click **Add to Print Area**, which puts each added block on its own page. To remove it, **Print Area**, **Clear Print Area**.

**1.5.2 Save workbooks in alternative file formats.** Go to the **File** tab and click **Export**. For PDF, click **Create PDF/XPS Document**, then the **Create PDF/XPS** button. In the **Publish as PDF or XPS** dialog set the file name, choose **Optimize for: Standard (publishing online and printing)** or **Minimum size (publishing online)**, and click **Options...** to set **Page range** and, under **Publish what**, **Selection**, **Active sheet(s)**, **Entire workbook** or **Table**, plus the **Ignore print areas** check box. Click **OK**, then **Publish**. For any other format, **File**, **Export**, **Change File Type**, pick from the **Workbook File Types** and **Other File Types** lists, click **Save As**, and confirm the entry in the **Save as type:** list.

**2.2.5 Apply number formats.** Select the numbers only. **Home** tab, **Number** group, open the **Number Format** list and pick the category, then adjust with **Increase Decimal** and **Decrease Decimal** underneath. For "currency without a symbol", the honest answer is the **Number** category with two decimals and the thousands separator on, set from the **Number** tab of Format Cells.

**2.2.6 Apply cell formats from the Format Cells dialog box.** Select the range, press **Ctrl+1**, and work across the six tabs, **Number**, **Alignment**, **Font**, **Border**, **Fill**, **Protection**, without clicking OK in between. On the **Border** tab set the **Style** and the **Color** before clicking a **Presets** button or an edge in the preview box; a border drawn before its style is chosen comes out in the previous style. Click **OK** once at the end.

**2.2.7 Apply cell styles.** Select the range. **Home** tab, **Styles** group, **Cell Styles**. The gallery opens in sections: **Good, Bad and Neutral**, **Data and Model**, **Titles and Headings**, **Themed Cell Styles**, **Number Format**. Hover for the live preview and click the style the task names.

**Expert 2.2.1 Create custom number formats.** Select the cells and press **Ctrl+1** to open Format Cells on the **Number** tab. Build the closest match first with a real category, because Excel remembers the code it just built: select **Date** and pick a pattern near the one you want. Then select **Custom** at the bottom of the **Category** list; the **Type** box already holds the code from the previous step, ready to edit. Type `dd-mmm-yy` over it. A custom format has up to four sections separated by semicolons, in the order positive, negative, zero, text. Click **OK**. To delete a code later, reopen the dialog, select **Custom**, select the code in the **Type** list and click **Delete**; only custom codes can be deleted.

## Notes on the source

`Homework Excel 4.xlsx` names its sheets `Hoja1` and `Hoja2`, the Spanish defaults, and keeps both instruction lists in text boxes floating over the data. Neither sheet carries a title row, so the tasks refer to "the database" and mean the whole used range. Task 5 on `Hoja2` says "set the document to four pages in total" without saying how they should be split; any arrangement that prints in four pages and keeps the repeated titles counts.
