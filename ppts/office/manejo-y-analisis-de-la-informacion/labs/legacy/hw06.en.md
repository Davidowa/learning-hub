# Homework 6 · VLOOKUP and IF

A travel agency has a departures board that holds only two facts per departure, the tour code and how many passengers booked. Everything else on the board has to be pulled from two reference tables further down the same sheet, and the last two columns have to be decided rather than looked up. It is a lookup exercise with a small IF at the end, and it is the first homework in this set where a formula has to reach a table by name instead of by address. Hand in the workbook with the shaded cells of the Expected Departures table filled.

**Objectives** MO-200 2.3.1, MO-200 4.1.2, MO-200 4.2.3, MO-200 2.2.5, MO-201 3.2.1

## What to do

1. Name the table that begins in cell `A16`. Route MO-200 2.3.1. The range to name is `A16:D25`, or `A17:D25` if the header is left out; either works with VLOOKUP as long as the first column of the named range is the tour code.
2. Name the table that begins in cell `A27`, the same way. The shipped workbook already carries a name for this one, see the notes below.
3. Fill the yellow cells of the Expected Departures table with formulas, taking the values from the two ranges named in the previous two steps. That means `B6:D14`, the tour description, the operator code and the operator responsible, and `G6:G14`, the amount collected. Nothing in those cells may be typed by hand. Routes MO-200 4.1.2 for reaching the name, MO-201 3.2.1 for the lookup itself.
4. Fill the blue cells, `F6:F14`, with the Group type, decided from the number of passengers in column `E`:
   - more than 20 passengers, the group is `Big`
   - more than 10 passengers, the group is `Regular`
   - fewer than that, the group is `Small`

   Route MO-200 4.2.3. Two conditions means one IF nested inside another.
5. The amount collected in `G6:G14` is the cost per trip for that tour multiplied by the number of passengers on that departure. Format the column as currency. Route MO-200 2.2.5.

The operator responsible is a two-step lookup and is worth pointing out before it is set as homework. The departures table holds a tour code, the tour table turns that into an operator code, and only the operator table turns the operator code into a name. So `D6` has to feed the result of one lookup into another, along the lines of `=VLOOKUP(VLOOKUP(A6,Tours,4,FALSE),Operadores,2,FALSE)`, or it can point at `C6` once column `C` is filled.

| 310 | Italy 3 days | C | España Tour | 8 | Small | 1,960 |
| 115 | Spain 10 days | A | Europamundo | 15 | Regular | 7,800 |

The nine amounts total 88,440.

Three tours appear more than once, `115` three times and `310` three times, so three pairs of rows must agree exactly on description, operator and unit cost. If two rows carrying the same tour code disagree, a lookup range was left relative and slid down while filling.

Column `F` must read `Big` three times, `Regular` three times and `Small` three times. Two departures carry exactly 10 passengers, and both are `Small`, because the rule is more than 10 and not 10 or more. A solution that returns `Regular` on those two rows has used `>=` where the instructions say greater than.

Change `C18`, the cost of `Spain 10 days`, from 520 to 600, and the three rows carrying tour `115` must each move on their own. If they do not, the cost was typed into the formula instead of looked up.

## Notes on the source

- The Tareas folder holds no homework 10. The set runs 1 to 9 and then jumps to 11. Nothing has been renumbered here to close the gap.
- The instruction sheet names the required file `Excel_Hmw6 (students)`. The workbook in the folder is `Hmw6_Excel(students).xlsx`. Same file, the two halves of the name are swapped.
- The instruction sheet refers to the sheet as `Exercise 1`. The sheet in the workbook is called `Ejercicio1`, in Spanish.
- Task 2 is already done in the shipped workbook. A workbook-scoped name `Operadores` is defined as `=Ejercicio1!$A$27:$B$30`, header row included. The table at `A16` carries no name, so task 1 is genuinely open. If the exercise is handed out as it stands, one of the two naming tasks is free, and the name that is there is in Spanish while everything else on the sheet is in English.
- The third bullet of the Group type rule reads "When the number of passengers is smaller, the quota is `Small`". It means the group type, not a quota. The word does not appear anywhere else in the exercise.
- The instructions say the amount collected "must consider the cost per trip and the total number of passengers" without naming the operation. Multiplication is the only reading that produces a currency figure, and it is the one used in the checks above.
- Column `A` of the departures table is labelled `Tour Code` with a capital C, and the same field in the tour table is labelled `Tour code`. The two tables also disagree on nothing else, so this is cosmetic.
