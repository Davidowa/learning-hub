# Legacy exercise 2 · Names, text joins and the imported homework file

The second of four exercises on one workbook, and the one that turns the grades report into something
that calculates. It opens the file saved at the end of legacy exercise 1, names the ranges, pulls the
enrolment IDs across by reference, builds the full name and the email address out of the name columns,
imports the homework marks from a separate CSV, and works the weighted theory grade out of the weight
row that has been sitting on row 3 since the beginning. What is handed in is the same workbook, saved
again, and legacy exercises 3 and 4 open it in turn.

**Objectives** MO-200 1.1.2, MO-200 1.2.3, MO-200 2.1.1, MO-200 2.1.3, MO-200 2.3.1, MO-200 3.3.2,
MO-200 4.1.1, MO-200 4.2.1, MO-200 4.3.3, MO-201 2.2.1.

## What to do

1. Name the cells before anything else. The banner cell is to be named `Title`, and every column is to
   take its own heading as its name. Route MO-200 2.3.1, using **Create from Selection** with **Top
   row** ticked for the columns. Excel will not accept spaces, apostrophes or parentheses in a name
   and substitutes underscores, so `Father's Last Name` and `Final grade (adj)` do not come back as
   typed; check what Name Manager actually holds before writing a formula against them.
2. Bring the IDs into column `B` by referring to the `IDs` sheet rather than copying, so the two stay
   linked. They have to end up as text, seven characters long, padded with leading zeros.
3. Build the full name in column `H` out of `Name`, `Father's Last Name` and `Mother's Last Name`
   with CONCATENATE. Route MO-200 4.3.3.
4. Build the email address in column `I` from the same pieces, this time with the `&` operator instead
   of a function, which is the point of the task.
5. Turn the address into a working link. The source gives the formula as
   `=hyperlink("mailto:"&I5)`, and asks for the way to remove hyperlinks to be shown as well.
   Route MO-200 1.2.3.
6. Add a date of birth column, which the sheet does not have, and copy the dates across from the `IDs`
   sheet. Route MO-200 2.1.3 for the column.
7. Sort the data, first on one criterion and then on several. Route MO-200 3.3.2.
8. Import `1.2 Homeworks.csv`. Route MO-200 1.1.2. The source puts it as a problem to solve rather
   than an instruction: the homework marks exist, but they are in another format.
9. Total each student's ten marks with SUM, sort the imported block by the same criterion used in task
   7, and line the two up row by row so the total can be matched to its student. Route MO-200 4.2.1.
10. Calculate the theory grade in column `Q` against the weights on row 3, pinning the references to
    row 3 so the formula fills down without dragging them with it. The shape is
    `=M5*M$3+N5*N$3+O5*O$3+P5*P$3`, and the same treatment gives `S5` the combined average,
    `=Q5*Q$3+R5*R$3`. Route MO-200 4.1.1, and the source asks for absolute, relative and mixed
    references to be explained here rather than only used.
11. Calculate the group's average grade, and the maximum and the minimum with it. Route MO-200 4.2.1.

## Notes on the source

- Task 2 says the IDs are on "the list on the next page". There is no such page in the surviving
  .docx, which ends with task 11 and carries no ID list. The only list of IDs is the `IDs` sheet in
  the workbook, and the instruction to reference rather than copy points at it.
- Task 2 also asks for two things that pull against each other. A custom number format only applies to
  numbers, so seven characters padded with zeros through the Format Cells dialog means the ID is no
  longer text; keeping it as text means the padding has to come from a formula such as
  `=TEXT(IDs!A2,"0000000")` or `=RIGHT("0000000"&IDs!A2,7)`. The source asks for both and does not say
  which wins.
- The IDs on the `IDs` sheet are six characters, not seven, so padding to seven adds one leading zero
  to every one of them: `084499` becomes `0084499`.
- Task 4 does not give a domain, or any pattern for the address beyond building it from the name
  columns with `&`.
- Task 6 does not say where the date of birth column goes. Next to `Age` is the only place it can be
  used from, since legacy exercise 3, task 7 calculates the age out of it.
- The source writes the hyperlink formula in lower case as `=hyperlink("mailto:"&I5)`. Excel accepts
  it and returns it upper case.
- The `Homeworks` column carries a weight of `0.1` and the homework total is a count from 0 to 10,
  which is why it can be dropped straight into a weighted average of grades that also run 0 to 10.
  The source never states that; it is read off the weight row.
- The source gives one task, task 10, for the calculation, while the weight row describes two columns:
  `Q` at the four weights that sum to 1, and `S` at `0.8` for theory and `0.2` for lab. Both are
  written out above on that reading. `T`, `Final grade (adj)`, is left for legacy exercise 3.
- The workbook ships with no defined names at all, so task 1 starts from nothing.
