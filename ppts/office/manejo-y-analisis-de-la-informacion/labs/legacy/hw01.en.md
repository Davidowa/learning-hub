# Legacy homework 1 · Formatting in Excel

Previous years' take-home on cell formatting. Two sheets, a quarterly sales table that has to be totalled and dressed, and a short vendor list that has to be numbered, styled and sorted. Nothing here needs a function beyond SUM and a division, and almost every mark comes from which dialog the formatting was applied from. The workbook is `Hmw1_Excel(students)_Formatting.xlsx` and the wording comes from `Homework1 Excel_Instructions.docx`. The instructions name no submission file name, so hand in the finished workbook under whatever name the course asks for that term.

**Objectives** MO-200 1.3.2, 2.1.2, 2.1.3, 2.2.1, 2.2.2, 2.2.4, 2.2.5, 2.2.6, 2.2.7, 3.3.2, 4.1.1, 4.2.1

## What to do

### Exercise1

1. Auto-adjust the column widths so that all the information is visible. Route MO-200 1.3.2.
2. To `B1:E1` apply merge and centre, Arial at size 14, bold and italic, a blue font colour, and all edges of the border. Routes MO-200 2.2.1 for the merge and MO-200 2.2.6 for the rest.
3. To the title row `A2:G2` apply bold, centred horizontally and aligned in the middle vertically, wrap text, and a fill of Blue, Accent 1, Lighter 40%. Routes MO-200 2.2.2, MO-200 2.2.4 and MO-200 2.2.6. The instructions call the fill `Ice Blue Fill, Accent 1, 40%`; see the notes at the end.
4. Right-align the word in `A10` and set it bold and italic.
5. To `A2:G10` apply borders from the **More Borders** entry of the Borders menu, or from the **Border** tab of the **Format Cells** dialog: a double outline in green, and a green dotted interior. Route MO-200 2.2.6. The instruction says explicitly that the dialog has to be used rather than the small border gallery.
6. Calculate the totals per column on row 10, `B10:E10`, with SUM. Route MO-200 4.2.1.
7. Calculate the annual total per row in `F3:F9`, again with SUM, and total that column in `F10`.
8. Fill the percentage column `G3:G9` by dividing each annual figure by the grand total in `F10`, with `F10` held absolute, for example `=F3/$F$10`. Route MO-200 4.1.1.
9. Format `G3:G9` as Percentage, and every other number on the sheet as Currency with 2 decimal places. Route MO-200 2.2.5.
10. Insert a column before the seller's name, so the names move from column A to column B. Route MO-200 2.1.3.
11. In the new `A3` write the code `V1`, then drag the fill handle down to write `V2` to `V7` for the rest of the sellers. Route MO-200 2.1.2.
12. Set the height of the totals row to 25 points, and align everything in that row in the middle vertically. Routes MO-200 1.3.2 and MO-200 2.2.2.

### Exercise2

13. Complete the `Vendor No.` column with the fill handle while holding `Ctrl`, so that `1` in `A2` becomes `1` to `7` down `A2:A8` instead of seven copies of `1`. Route MO-200 2.1.2.
14. Select the title row and apply wrap text, centred horizontally and aligned in the middle vertically. Routes MO-200 2.2.4 and MO-200 2.2.2.
15. Apply a cell style of any colour to the titles. Route MO-200 2.2.7.
16. Format the sales values as Currency. Route MO-200 2.2.5.
17. Set the three sales columns to a width of 12, and raise the height of the header row so that the title text shows on two lines. Route MO-200 1.3.2.
18. Apply full borders in the same colour used for the titles. Route MO-200 2.2.6.
19. Sort the information by last name. Route MO-200 3.3.2.

## Notes on the source

- The instructions give no submission file name and no due date. The current homework set names its file `Homework N Excel_Your name.xlsx`; nothing in this document says the same rule applied.
- `A10` on `Exercise1` holds `Totales`, in Spanish, while the instruction asks to right-align "the word Totals". They are the same cell.
- The fill named in the instructions, `Ice Blue Fill, Accent 1, 40%`, is a translation of the Spanish swatch name. The English gallery calls that swatch **Blue, Accent 1, Lighter 40%**, and it is the fourth column of the theme colours, second row down.
- The instruction sheet has a typo, "you musts display the Borders/More Borders menu".
- Exercise 2 asks for sales columns "12 points wide". Column width in Excel is counted in characters, not points; row height is the measurement in points. Read it as a width of 12.
- Nothing in the instructions says whether the `Vendor No.` column travels with the rows when the sheet is sorted by last name. If the whole block is selected, the numbers move with their vendor and end up out of order; if only column B is sorted, the data is scrambled against the numbers. Decide which one is being graded before marking it.
- Neither sheet ships with any formatting applied, so there is nothing to clear before handing the file to students. Both are clean starting points.
