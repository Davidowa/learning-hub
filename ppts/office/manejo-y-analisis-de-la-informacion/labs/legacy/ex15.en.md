# Legacy exercise 15 · What-if analysis on the Churrumpin model

One small profit model for a homemade cleaning product, then five questions asked of it with the three what-if tools: Goal Seek for the break-even volume, a one-variable data table across volume, a two-variable data table across price and cost, and Scenario Manager for three futures. The whole exercise is one paragraph of givens and a five-row table of instructions. The student hands in the workbook they built.

**There is no workbook.** The `Ejercicio 15 (What if analysis)` folder holds `EXERCISE 15.docx` and nothing else, and the required-files line of that document reads `Create New File`. Everything below is typed from scratch, which is also why this file has no CSV link and no inline data table: there is no sheet to export.

**Objectives** MO-200 2.2.5, MO-201 3.4.2

Data tables are the third what-if tool and they are not a numbered objective on either exam. Goal Seek and Scenario Manager are both MO-201 3.4.2, and the **Data Table** dialog sits on the same menu as both without appearing in the objective domain. Two of the five tasks here are data tables, so most of this exercise is graded on the result rather than on a route.

## What to do

The source gives each task twice, once as an instruction and once as the command that answers it. Both are kept, the command in italics.

1. Calculate Net Profit. The source's own command column reads `(Units*Price) – (Variable Cost*Price) – Fixed Costs – Taxes`. The formula as printed does not work; see the notes. The chain in the layout table above is the working version, and `B14` is the cell every later task points at. Format the currency cells with two decimals and `B7` as a percentage. Route: MO-200 2.2.5.
2. Calculate the minimum sales volume to break even. *Data > What if analysis > Goal Seek.* Select `B14`, set **To value** to `0` and **By changing cell** to `B3`. Route: MO-201 3.4.2. Write the answer down before doing anything else: Goal Seek overwrites `B3` with a plain number and leaves nothing behind that says it ran. Put 50,000 back afterwards.
3. Calculate profit with a variation in volume between 30,000 and 70,000 with intervals of 5,000. *Data > What if analysis > Data Table.* Nine volumes down a column, `=B14` in the cell one row above and one column to the right of the first volume, select the whole block including both, and run **Data Table** with `B3` as the **Column input cell** and **Row input cell** left empty.
4. Calculate profit with a variation in price and cost. The price between $50 and $80 and the cost between $20 and $40, in 5-to-5 intervals. *Data > What if analysis > Data Table.* Seven prices down the left column, five costs across the top row, `=B14` in the corner where the two meet, and **Data Table** with `B5` in **Row input cell** and `B4` in **Column input cell**, or the other way round if the axes are swapped. Getting those two boxes the right way round is the whole of this task.
5. Calculate three possible scenarios: optimistic, pessimistic and realistic. *Data > What if analysis > Scenario Manager.* Route: MO-201 3.4.2. The source gives no values for the three; see the notes.

## Checks

At the given inputs, revenue is 3,500,000, variable cost is 1,500,000, contribution is 2,000,000, profit before tax is 500,000, tax is 75,000 and net profit is **425,000**.

Break-even is at **37,500 units**. Fixed costs of 1,500,000 divided by a margin of 40 per unit, and the tax rate does not move it, because fifteen per cent of nothing is nothing. If Goal Seek returns something near 37,500 but not exactly, it stopped on its default precision; that is expected and the answer is 37,500.

The one-variable table, nine rows:

| Units | Net profit |
|---|---|
| 30,000 | -255,000.00 |
| 35,000 | -85,000.00 |
| 40,000 | 85,000.00 |
| 45,000 | 255,000.00 |
| 50,000 | 425,000.00 |
| 55,000 | 595,000.00 |
| 60,000 | 765,000.00 |
| 65,000 | 935,000.00 |
| 70,000 | 1,105,000.00 |

Every step of 5,000 units moves net profit by 170,000, which is 5,000 units at a 40 margin less fifteen per cent tax. A column that does not step evenly means the input cell was wrong. A column that repeats 425,000 all the way down means the **Column input cell** was left empty, so the table computed the same model nine times.

The two-variable table, seven prices by five costs, all at 50,000 units:

| | Cost 20 | Cost 25 | Cost 30 | Cost 35 | Cost 40 |
|---|---|---|---|---|---|
| **Price 50** | 0 | -212,500 | -425,000 | -637,500 | -850,000 |
| **Price 55** | 212,500 | 0 | -212,500 | -425,000 | -637,500 |
| **Price 60** | 425,000 | 212,500 | 0 | -212,500 | -425,000 |
| **Price 65** | 637,500 | 425,000 | 212,500 | 0 | -212,500 |
| **Price 70** | 850,000 | 637,500 | 425,000 | 212,500 | 0 |
| **Price 75** | 1,062,500 | 850,000 | 637,500 | 425,000 | 212,500 |
| **Price 80** | 1,275,000 | 1,062,500 | 850,000 | 637,500 | 425,000 |

That grid has a diagonal of zeros running from the top left to the bottom right, wherever price minus cost is exactly 30, because 50,000 units at a margin of 30 covers the fixed costs and leaves nothing. It is the fastest way to see whether the two input cells were swapped: swap them and the diagonal survives but every other cell moves, since the grid is not symmetric. Check one off-diagonal cell as well, `Price 80, Cost 20`, which has to read 1,275,000.

The cell at `Price 70, Cost 30` is the model's own answer, 425,000. If it is not, the corner formula does not point at `B14`.

## Notes on the source

- **There is no workbook, and there never was.** The required-files line reads `Create New File`. Typing the model is part of the exercise, and it means there is no shipped answer to check against, which is why the Checks above were computed from the givens rather than read off a sheet.
- **The profit formula as printed is wrong.** The source writes `(Units*Price) – (Variable Cost*Price) – Fixed Costs – Taxes`. Variable cost multiplied by price is not a quantity that exists; it has to be units multiplied by unit cost. The line is also circular as written, because taxes are computed from the profit the line is calculating. Read as intended, it is: revenue less variable cost less fixed costs gives profit before tax, and tax is fifteen per cent of that. The chain in the layout table does exactly that in six cells.
- **The three scenarios have no values.** Task 5 asks for optimistic, pessimistic and realistic and stops there. It does not say which cells vary, by how much, or which cells the summary should report. Any three sets of inputs satisfy it, which makes it ungradeable as written. The obvious repair is to name the changing cells, `B3`, `B4` and `B5`, and give a figure for each of the three, and none of that is in the original.
- **A loss is taxed.** `B13` is `=B12*B7` with no floor, so at 30,000 units the model computes a tax of -45,000 and reports a loss of 255,000 instead of 300,000. The nine-row table above shows the model's own numbers, tax credit and all. Whether to fix it with `=MAX(0,B12)*B7` is a modelling question the source never raises, and fixing it changes the first two rows of the data table and nothing else.
- **"5-to-5 intervals"** in task 4 means steps of 5. With a price band of 50 to 80 that gives seven prices and with a cost band of 20 to 40 it gives five costs, so the grid is 7 by 5 and the block including the headings is 8 by 6.
- **The document is headed `EXERCISE 15- What-if Analysis` and carries a bare heading `EXERCISE`** above the paragraph of givens, with no number after it. It is the same template leftover as in [legacy exercise 14](ex14.en.md).
- **The folder jumps from 12 to 14.** There is no `Ejercicio 13` in the previous years' material, and the instruction file inside the `Ejercicio 14` folder is titled `EXERCISE 13`. Exercise 15 is the last of the numbered previous years' exercises.
- **Scenario Manager is asked for here and nowhere else.** The current [exercise 25](../ex25.en.md) covers the same Churrumpin model with Goal Seek and a one-variable data table and then drops both the price-and-cost grid and the scenarios, which leaves half of MO-201 3.4.2 without a practice file in the current material. Task 5 above is the only place the objective is exercised, and it is the task with no values in it.
