# Legacy exercise 4 · Printing, protection and the PDF

The last of four exercises on one workbook, and the only one that produces nothing new on the page.
It tidies the file up for delivery: the working sheets are hidden, protected or deleted, the two sheets
that matter are given a print area, a scale, an orientation, a header, a footer and repeating titles,
and the whole thing goes out as a PDF. There is no file of its own and no data to link. Everything it
touches was made in legacy exercises 1, 2 and 3.

**Objectives** MO-200 1.3.1, MO-200 1.3.3, MO-200 1.4.6, MO-200 1.5.1, MO-200 1.5.2, MO-200 1.5.3,
MO-201 1.2.2. Hiding and deleting a worksheet are asked for in tasks 1 and 3 and carry no objective
code of their own in either exam.

## The data

None. This is an instruction-only exercise. It opens the workbook saved at the end of legacy exercise
3, which by then holds `TOTAL BASE` with its 54 students, the `IDs` sheet, `Base2` left empty by the
cut in legacy exercise 1, the sheet the homework CSV was imported onto, and `Analysis` with its four
charts. The sheets themselves are
described in [ex01.en.md](ex01.en.md).

## What to do

1. Hide the `IDs` sheet. It is still needed, because the IDs and the dates of birth in `TOTAL BASE`
   refer to it, and it is not meant to be seen.
2. Protect the homework sheet so nobody can change it. Route MO-201 1.2.2. The source does not say
   which settings to leave ticked, and the sheet has no name in any of the four documents; see the
   notes.
3. Delete `Base2`. Its 18 students were folded into `TOTAL BASE` back in legacy exercise 1, task 11,
   so it is a duplicate. The source asks for inserting a sheet and for Move or Copy to be shown at the
   same time.
4. Set up the printing. On `TOTAL BASE`, the print area is the data area only, scaled to 1 page tall
   by 2 pages wide, in landscape. On `Analysis`, the print area has to take in the charts as well as
   the figures. Routes MO-200 1.5.1 for the print area, MO-200 1.3.1 for the orientation and the
   scaling, MO-200 1.5.3 for the rest.
5. Put `FINAL GRADES` in the header and your own name in the footer. Route MO-200 1.3.3.
6. On `TOTAL BASE`, repeat the `Num` and `ID` columns on every printed page, and print the row and
   column headings. Route MO-200 1.5.3. The two columns are `A` and `B`, so the print title is
   `$A:$B`.
7. Work out how to print the `Analysis` sheet with its formulas showing instead of its results.
   Route MO-200 1.4.6.
8. Produce a PDF of the charts. The source asks for the difference between Save As with PDF chosen and
   printing to a PDF driver to be explained rather than just used. Route MO-200 1.5.2.

## Checks

- The tab bar at the end shows `TOTAL BASE`, the homework sheet and `Analysis`. `Base2` is gone and
  `IDs` is hidden, which means it does not appear on the tab bar but does appear in the Unhide dialog.
- The formulas in `TOTAL BASE` that point at `IDs` still return values after task 1. Hiding a sheet
  does not break a reference to it; deleting one does, which is why task 3 names `Base2` and not `IDs`.
- Typing into the protected sheet raises the dialog that says the cell is on a protected sheet.
- Print Preview on `TOTAL BASE` shows two pages across and one down, in landscape, with the columns
  `Num` and `ID` on both pages and the row numbers and column letters printing.
- Print Preview on `Analysis` shows the charts and not just the numbers.
- The header reads `FINAL GRADES` on every page and the footer carries a name.
- With task 7 applied, the `Analysis` sheet prints `=COUNTIF(...)` where it printed a number, and its
  columns widen on screen while the setting is on.
- The PDF opens outside Excel and holds the charts.

## Notes on the source

- Task 2 protects "the Homework sheet". No sheet in the workbook has that name. The homework data
  arrives as an import in legacy exercise 2, task 8, and none of the four documents says what the
  sheet it lands on should be called, so the name has to be agreed with the class before this task can
  be graded.
- The workbook as shipped has no protection set on any sheet, no hidden sheets and no print settings
  of any kind: no print area, no print titles, no header, no footer and no scaling. Everything in this
  exercise is created from nothing, which also means there is no original to compare a student's file
  against.
- Task 2 does not list which of the protection allowances to leave ticked, and does not say whether a
  password is wanted.
- Task 4 gives the scaling as 1 tall by 2 wide and the orientation as horizontal, which is landscape;
  it does not give a paper size or margins.
- Task 6 says to repeat "the number and ID", which are the `Num` and `ID` columns inserted in legacy
  exercise 1, task 9. Repeating columns on every page is Columns to repeat at left in the Sheet tab of
  Page Setup, and it takes whole columns, so `$A:$B` rather than a cell range.
- Task 7 is written as a question rather than an instruction, which is how the source hands the class
  something to work out.
- Task 8 asks for a PDF "of the charts" without saying whether that means the chart sheet alone, the
  print area set in task 4, or the whole workbook.
