# Exercise 15 · AutoFilter over an appliance sales log

Week 9, session 18, the filters session. Four hundred and eight sales, and six filters that each pick a different route through the same column headers: a date range, a single month, a fill colour, a text pattern, a conditional formatting icon, and a top ten. The formatting in the first half of the exercise is not decoration, it is what makes filters three to six possible at all, so do it in order. Hand in the workbook with the four calculated columns, both conditional formats, the hand-coloured cells, and a screenshot or a saved state of each of the six filters.

**Objectives** MO-200 1.3.2, MO-200 2.2.4, MO-200 2.2.5, MO-200 2.2.6, MO-200 2.4.2, MO-200 3.3.1, MO-200 3.3.2, MO-200 4.1.1, MO-201 2.3.1

## The data

One sheet, named `Hoja1` in the source file. Headers in row 1, data in `A2:J409`, four hundred and eight rows. Too many to retype, so it lives in [`labs/data/ex15-sales.csv`](data/ex15-sales.csv), ten columns, no answer columns to leave out because every calculated column is new.

| Column | Header | Holds |
|---|---|---|
| A | Sale Date | An Excel date serial, 43101 to 43466, with no date format applied |
| B | Product | 25 distinct products, in Spanish, upper case |
| C | Brand | 12 brands |
| D | Category | Línea Blanca, TV/Video/DVD, Electro, Audio, Depiladoras, Aire Acondicionado |
| E | Branch | Abasto, Centro, Coyoacan, Del Valle, Roma, San Angel |
| F | Vendor | 17 vendor codes |
| G | Payment | Cash or Credit Card |
| H | Unit cost | Whole pesos |
| I | Unit selling price | Whole pesos |
| J | Quantity | Units sold on that line |

Column A is the reason task 1 exists. The values are stored as plain numbers with the **General** format, so 43101 sits in the cell where 1 January 2018 belongs. Applying a date format is what turns the column back into dates, and nothing else in the exercise works until it does.

Two details worth knowing before the date filters. The set runs from 1 January 2018 to 1 January 2019, so two records fall outside 2018 even though every task talks about 2018. And the Brand column holds both `PHILIPS` and `Philips`, which matters for the text filter in task 7 and does not matter at all, because Excel's text filters ignore case.

## What to do

### Formatting

1. Autofit every column to its content, so no cell shows `#####` and no product name is clipped.
2. Give column A a date format.
3. Give columns H and I a currency format.
4. Format the header row `A1:J1` in one pass: green fill, wrapped text, centred horizontally and vertically, white bold font.
5. Put simple borders on the whole block, header row included.

Tasks 4 and 5 are one operation each, not four and two. Fill, font, alignment and border all live on tabs of the same dialog, and doing them from the ribbon costs the item.

### Calculated columns

6. Add four new headers in `K1:N1`: `Total Cost`, `Total Sale`, `Total Profit`, `% Profit`. Then write one formula per column in row 2 and fill down to row 409:

| Cell | Formula | Meaning |
|---|---|---|
| K2 | `=H2*J2` | Unit cost times quantity |
| L2 | `=I2*J2` | Unit selling price times quantity |
| M2 | `=L2-K2` | Total sale minus total cost |
| N2 | `=M2/L2` | Profit as a share of the sale |

All four use relative references, which is the whole reason one formula fills 408 rows. Format column N as a percentage.

`% Profit` is profit over sale, not profit over cost. The distinction decides task 8: measured against sale, the column runs from 29.98 % to 45.18 % and the three colours all get used; measured against cost it runs from 42.8 % to 82.4 % and every row is green.

### Conditional formatting

7. Column L, `Total Sale`: apply a three-arrow icon set from the preset gallery.
8. Column N, `% Profit`: apply a three-symbol traffic light icon set with the thresholds typed in rather than left on the automatic percentages. Red below 30 %, yellow from 30 % to 40 %, green above 40 %. Presets cannot express that, so this one goes through **New Rule...**.

### Cell formatting by hand

9. In column B, pick five cells at random and give them a yellow fill.
10. In the same column, pick five other cells and set the font colour to red, then five more and set it to blue.

These fifteen cells exist so that task 13 has something to filter on. Keep them scattered, and write down which rows you coloured, because the filter result is the only way to prove it afterwards.

### Filters

11. Turn on the filter arrows, then filter the Sale Date column to the first quarter of 2018.
12. Clear that, and filter the Sale Date column to September 2018.
13. Clear that, and filter the Product column by cell colour, then by font colour.
14. Clear that, and filter the Brand column to the records that begin with `PH`.
15. Clear that, and filter the Total Sale column by icon.
16. Clear that, and get the ten largest sales, sorted highest to lowest.

## Exam routes used here

### MO-200 1.3.2, adjust row height and column width

1. Select the columns by clicking their headings. Drag across headings, or `Ctrl`-click for a non-adjacent set.
2. Go to the **Home** tab, **Cells** group, and click **Format**.
3. Click **AutoFit Column Width**.
4. For a specific number instead, click **Format**, then **Column Width...**, type the value in the **Column width:** box and click **OK**. The unit is characters of the standard font, not points.

**Short route, not graded.** Drag the border between two column headings, or double-click that border to autofit. Dragging is the one that costs marks: a task that says "set the width of column C to 18" cannot be satisfied by a drag, because 18 is not a position the mouse can find.

**Shortcut.** `Alt`, `H`, `O`, `I` for AutoFit Column Width. There is no Ctrl combination.

**How to check it.** No cell in the block shows `#####` and no text is clipped at the right edge.

### MO-200 2.2.5, apply number formats

This objective is the ribbon one on purpose. Certiport separates it from 2.2.6 precisely so that one item tests the Number group and the other tests the dialog. Do not answer this one from Format Cells unless the task says so.

1. Select the range. Select the numbers only, not the header.
2. Go to the **Home** tab, **Number** group.
3. Open the **Number Format** list at the top of the group. It reads **General** by default.
4. Pick the format: **Short Date** or **Long Date** for column A, **Currency** for columns H and I, **Percentage** for column N.
5. Adjust with the buttons underneath: **Accounting Number Format** with its arrow for the currency symbol, **Percent Style**, **Comma Style**, **Increase Decimal**, **Decrease Decimal**.

**Currency** and **Accounting** are not the same and the exam knows it. Currency puts the symbol tight against the digits and shows negatives in the style chosen in the dialog. Accounting lines the symbols up on the left edge of the cell, lines the decimal points up, shows zero as a dash, and puts negatives in parentheses. The task says currency.

**Short route, not graded.** Typing the format into the cell and letting Excel infer it. A format does get applied, but Excel picks which one. The nastier version: typing `50%` into a cell that already holds `50` turns the value into 0.5, so the underlying data is now wrong and every formula downstream is wrong with it.

**How to check it.** Select `A2`. The **Number Format** list must read the date format you chose, and the formula bar must still show `43101` as a date rather than as text. Numbers align right by default; a date that landed left is text.

### MO-200 2.2.6, apply cell formats from the Format Cells dialog box

This is the route for tasks 4, 5, 9 and 10. The result is reachable two ways and only one of them is graded.

1. Select the cell or range.
2. Press **Ctrl+1**. With the mouse, go to the **Home** tab and click the dialog box launcher of the group you need, the small diagonal arrow in the bottom right corner of the **Font**, **Alignment** or **Number** group. All three open the same **Format Cells** dialog, only on a different tab.
3. The dialog has six tabs across the top: **Number**, **Alignment**, **Font**, **Border**, **Fill**, **Protection**.
4. **Font tab.** Set **Font style** to Bold and open the **Color** list for white.
5. **Do not click OK.** Click the **Fill** tab and click the green swatch under **Background Color**.
6. Click the **Alignment** tab. Set **Horizontal** to **Center**, **Vertical** to **Center**, and select **Wrap text** under **Text control**.
7. Still without closing, click the **Border** tab. **Order matters on this tab and it is the most common way to lose the item.** Choose the **Style** from the Line box and the **Color** from the Color list **first**, then click a **Presets** button (**None**, **Outline**, **Inside**) or click the individual edges in the **Border** preview box. A border drawn before the style is set comes out in the previous style, and clicking the style afterwards does nothing to it.
8. Click **OK** once. Every tab that was touched is applied in a single operation.

![Format Cells, the Border tab](../../../img/en/format-cells-border.png)

*The Border tab that step 7 is about. Style and Color sit on the left, the three Presets and the preview box on the right, and a preset clicked before the style is chosen draws the border in whatever style was already there.*

**Why the route is the whole point.** Do it from the dialog and one press of **Ctrl+Z** takes back the font colour and the fill together. Do it from the ribbon and it takes two presses. That single undo is the visible proof of which route was taken.

**Short route, not graded.** Go to the **Home** tab, **Font** group. Click the arrow next to **Font Color** and pick a colour. Click the arrow next to **Fill Color** and pick another. Click **Borders** and pick a preset. Three clicks, three separate operations, identical picture on screen.

**Shortcut.** **Ctrl+1** opens Format Cells on whichever tab was last used. **Ctrl+Shift+F** opens it on the **Font** tab. Inside the dialog, **Ctrl+Tab** moves to the next tab and **Ctrl+Shift+Tab** to the previous one. **Enter** is OK, **Esc** is Cancel and throws away every tab.

**How to check it.** Reselect `A1:J1` and press Ctrl+1, then walk the tabs: every setting must be showing where it was set. Then press **Ctrl+Z** exactly once. If the font colour and the fill both disappear together, the dialog did it.

### MO-200 2.2.4, wrap text within cells

The header row needs wrapping, and the objective is counted separately from the rest of the dialog.

1. Select `A1:J1`.
2. Go to the **Home** tab, **Alignment** group, and click **Wrap Text**.
3. Or press `Ctrl+1`, go to the **Alignment** tab, and select **Wrap text** under **Text control**. That is the route step 6 above already takes, and it counts for both objectives at once.

![Format Cells, the Alignment tab](../../../img/en/format-cells-alignment.png)

*The Alignment tab, with Wrap text sitting under Text control. The same visit sets Horizontal and Vertical to Center, which is how one trip to the dialog answers this objective and 2.2.6 together.*

**How to check it.** Widen a column. Wrapped text reflows and the row height follows; text broken with `Alt+Enter` keeps its break wherever the column goes.

### MO-200 4.1.1, insert relative, absolute, and mixed references

1. Click `K2` and type `=`.
2. Click `H2`, type `*`, click `J2`. Both arrive relative.
3. Press `Enter`.
4. Fill down to row 409 with the fill handle or `Ctrl+D`.
5. Click `K409` and read the formula bar. It must read `=H409*J409`. If it still reads `=H2*J2`, a dollar sign got in by mistake.

**Shortcut.** `F4` cycles `H2`, `$H$2`, `H$2`, `$H2`. Nothing in this exercise needs anything but the first form, which makes it a good place to see what happens when a reference is locked by accident.

### MO-200 2.4.2, apply built-in conditional formatting

This is task 7, the three arrows on Total Sale.

1. Select `L2:L409`. Data cells only. Including the header row is the most common cause of a rule that formats the wrong cells, because a text header counts as smaller than every number.
2. Go to the **Home** tab, **Styles** group, and click **Conditional Formatting**.
3. Point at **Icon Sets**. Hover the gallery for live preview.
4. Click the three-arrow variant under **Directional**.
5. Click **More Rules...** at the bottom of the gallery if the thresholds have to be typed rather than left on the automatic percentages. That dialog is the next route.

**Short route, not graded.** Reading the numbers, then colouring the cells that meet the condition by hand with a fill. It is identical on screen the moment it is done, and it is not conditional formatting. This is the single most common way to lose points in this objective, and on this sheet it also breaks task 15, because there is no icon to filter by.

**Shortcut.** None. Ribbon keys: **Alt, H, L**.

**How to check it.** Change a value in column J so a row's Total Sale crosses a band, then change it back. A real rule repaints itself instantly. Second check: **Conditional Formatting**, **Manage Rules...**, with **Show formatting rules for** set to **This Worksheet**. The rule must be listed with `=$L$2:$L$409` in **Applies to**.

### MO-201 2.3.1, create custom conditional formatting rules

This is task 8, the traffic light with typed thresholds.

1. Select `N2:N409` first. The rule is stored against the range that was selected when it was made, and fixing that afterwards means editing **Applies to** by hand.
2. Go to the **Home** tab, **Styles** group, click **Conditional Formatting**, then click **New Rule...**.
3. In **Select a Rule Type**, click **Format all cells based on their values**.
4. Open **Format Style** and pick **Icon Set**.
5. Open the **Icon Style** list and pick the three traffic lights.
6. Set the bands from the top down. Green when the value is `>=` `0.4`, with **Type** set to **Number**. Yellow when `>=` `0.3`, **Type** **Number**. Red takes everything else.
7. Select **Reverse Icon Order** if green came out at the bottom, and **Show Icon Only** if the task asks for the number hidden. Neither is asked for here.
8. Click **OK**.

![The New Formatting Rule dialog](../../../img/en/new-formatting-rule.png)

*New Formatting Rule, with the six rule types at the top and the rule description below them. The shot has Format Style on 2-Color Scale; step 4 changes that list to Icon Set, and the Minimum and Maximum rows become the bands you type the thresholds into.*

Type matters more than the numbers. Leave **Type** on **Percent** and Excel reads 30 as "thirty per cent of the way from the smallest value to the largest", not "0.30", and the bands land somewhere else entirely.

**Short route, not graded.** Take the traffic lights straight from the **Icon Sets** gallery and leave the thresholds alone. That does apply a conditional format, and it is the correct answer when the task names a preset. When the task names the thresholds, the preset route cannot express them.

**Shortcut.** None for New Rule. `Ctrl+1` does not work inside the rule dialog; the **Format...** button is the only way to a format from there.

**How to check it.** Open **Manage Rules...** and read the rule's **Format** preview. Then find a row whose `% Profit` sits at exactly 30 % and confirm which icon it carries. `>=` and `>` differ on that row, which is where the check goes.

### MO-200 3.3.1, filter records

Tasks 11 to 16 all start here.

**Value filter.**

1. Click any cell in the block. In a plain range, first go to the **Data** tab, **Sort & Filter** group, and click **Filter** to put the arrows on the header row.
2. Click the filter arrow in the header of the column to filter.
3. Clear the **(Select All)** check box. Every value clears with it.
4. Select only the values the task names. Use the **Search** box above the list when the list is long, then select **Add current selection to filter** if you are building the selection in passes.
5. Click **OK**.

Date columns get an extra layer here: the value list groups itself by year, then month, then day, with a check box at each level. September 2018 is one click on that tree once the year is expanded, which is the route task 12 wants.

**Criteria filter.**

1. Click the filter arrow in the column header.
2. Point to **Number Filters**, **Text Filters** or **Date Filters**. Excel offers the one that matches the column's data type, which is another reason column A has to be formatted as dates before task 11.
3. Click the operator the task names: **Between...** for the quarter, **Begins With...** for the brand, **Top 10...** for the last one.
4. In the **Custom AutoFilter** dialog, type the value in the box to the right of the operator.
5. For a second condition, select the **And** or the **Or** option button and fill the second row. Use `?` for one character and `*` for any run of characters.
6. Click **OK**.

**Colour and icon filters.** Not recorded click by click in `procedures.en.md`, which names them only in its short route, so treat the captions below as **TO CONFIRM** against the lab build.

1. Click the filter arrow in the header of the column that carries the colours or the icons.
2. Point at **Filter by Color**.
3. The submenu lists what actually exists in that column, under **Filter by Cell Color**, **Filter by Font Color** and **Filter by Cell Icon**. A column with no fills shows no cell-colour swatches at all, which is the fastest way to find out that task 9 was skipped.
4. Click the swatch or the icon.

Only one colour or icon can be picked at a time. That is a limit of AutoFilter, not a mistake, and it is why tasks 9 and 10 ask for three separate groups of five cells.

**Clearing.**

1. To clear one column, click that column's filter arrow and click **Clear Filter From "Column name"**.
2. To clear every filter and keep the arrows, go to the **Data** tab, **Sort & Filter** group, and click **Clear**.
3. To remove the arrows as well, click **Filter** in the same group.

**Short route, not graded.** Right-click a cell holding the value you want, point to **Filter**, and click **Filter by Selected Cell's Value**. The submenu also offers **Filter by Selected Cell's Color**, **Filter by Selected Cell's Font Color** and **Filter by Selected Cell's Icon**. One click, correct result, and it only exists when the criterion is already sitting in a cell.

**Shortcut.** `Ctrl+Shift+L` turns the filter arrows on and off. `Alt+Down Arrow` on a header cell opens that column's filter menu without the mouse.

**How to check it.** The filter arrow turns into a funnel icon on the filtered column, the row headings of the surviving rows turn blue, and the hidden row numbers are missing. The status bar at the bottom left reads how many of how many records were found, and that is the number to compare against the table below.

### MO-200 3.3.2, sort data by multiple columns

Task 16 needs a sort on top of the filter.

1. Click any single cell inside the block. Do not preselect one column, which is how you tear the rows apart.
2. Go to the **Data** tab, **Sort & Filter** group, and click **Sort**.
3. Select the **My data has headers** check box.
4. Open **Sort by** and pick `Total Sale`, leave **Sort On** at **Cell Values**, and open **Order** to pick **Largest to Smallest**.
5. Click **OK**.

![The Sort dialog](../../../img/en/sort-dialog.png)

*The Sort dialog with its one level row waiting and Sort On already reading Cell Values. Ticking My data has headers is what puts `Total Sale` in the Sort by list instead of `Column L`.*

**Short route, not graded.** Click in column L and use **Sort Z to A** on the Data tab. It reaches the same arrangement on a single-level sort and leaves no sort levels behind for the grader to read.

**How to check it.** Reopen the **Sort** dialog. The level you defined is still listed.

Numbers that do not move, for the calculated columns:

| Figure | Value |
|---|--:|
| Data rows | 408 |
| Sum of Total Sale | 72,634,429 |
| Sum of Total Cost | 48,427,010 |
| Sum of Total Profit | 24,207,419 |
| Overall % Profit | 33.33 % |
| Lowest % Profit in the file | 29.98 % |
| Highest % Profit in the file | 45.18 % |
| Largest single Total Sale | 1,098,405 |
| Tenth largest Total Sale | 610,225 |

The traffic light bands split the 408 rows as 66 red, 221 yellow and 121 green. The task wording leaves 30 % and 40 % themselves undefined, and it does not matter here: no row in the file lands on either boundary, so `>=` and `>` produce the same three counts. If every row comes out green, `% Profit` was calculated against cost instead of against the sale. If every row comes out red, or the split is roughly even, the icon set thresholds were left on **Percent** instead of **Number**.

Four more things to look at.

- The brand filter returns 131 rows across `PHILIPS`, `PHILCO` and `Philips`. If it returns 130, the lower-case `Philips` was excluded, which means the criterion was written as something case sensitive rather than as **Begins With**.
- Filtering to 2018 as a whole returns 406, not 408. Two records are dated 1 January 2019. The exercise is written as though the file were a 2018 data set, and it is not quite.
- Clear every filter and confirm the row count returns to 408. A **Top 10** left in place looks like a finished sheet and is a filter that is still on.
- Select `L2:L409` and open **Manage Rules...**. Two rules must be listed for the sheet, one on column L and one on column N, each with its own **Applies to** range. One rule covering both columns means the second selection included the first.
