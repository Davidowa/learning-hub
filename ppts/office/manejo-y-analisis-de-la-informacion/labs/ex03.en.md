# Exercise 3 · Conditional formatting, sparklines and links

Thirty students, ten subjects, one average worked out once and then copied into eight columns so that eight different conditional formatting rules can be laid over the same numbers side by side. That side-by-side layout is what makes the exercise work: the student sees a highlight rule, a rank rule, a percentile rule, an above-average rule, an icon set, a data bar and a colour scale all reading the same values and painting them differently. After that come sparklines and four kinds of hyperlink. It lands in week 5, sessions 9 and 10, where COBERTURA pairs it with Exercise 7. Hand in the finished workbook as `Exercise 3 Excel_Your name.xlsx`.

The source folder is called `Ejercicio3_`, with nothing after the underscore. The instruction document supplies the missing name: conditional formatting, sparklines and links.

**Objectives** MO-200 1.2.3, 1.4.3, 2.1.4, 2.4.1, 2.4.2, 4.1.1, 4.2.1; MO-201 2.3.1

## What to do

1. Open the workbook and go to the `Conditional formatting` sheet.
2. Repair the grades. The block from H14 down was entered one row too low, which is why H13:L13 is empty and why five orphan grades sit on row 34 under nobody's name. Select H13:L13, delete the cells, and choose **Shift cells up**. Every row from 13 to 33 realigns and row 34 empties. Route 2.1.4.
3. In N4, average the ten subject grades with `=AVERAGE(C4:L4)`. Route 4.2.1.
4. In O4, write `=N4`. The other seven answer columns hold the same average, so a relative reference to the cell on the left is all each one needs. Fill O4 across to U4. Route 4.1.1.
5. Fill N4:U4 down to row 33, so the whole block N4:U33 carries the average. Copy with `Ctrl+C` and paste, or select the first row and drag it down.
6. Freeze the panes at C4, so the student names, the status column and the three header rows stay on screen while the grades scroll. Route 1.4.3.
7. Column N, highlight every average of 60 or more with a green fill. This one needs **New Rule...**, because the preset menu has **Greater Than...** and no **Greater Than Or Equal To**. Pick **Format only cells that contain**, set the description to `Cell Value` `greater than or equal to` `60`, and set the fill from the **Format...** button. Route Expert 2.3.1.
8. Column O, highlight averages below 60 with a red fill. **Highlight Cells Rules** > **Less Than...**, value `60`. Route 2.4.2.
9. Column P, highlight the top 10 values with **Yellow Fill with Dark Yellow Text**. **Top/Bottom Rules** > **Top 10 Items...**. Route 2.4.2.
10. Column Q, highlight the bottom 10 per cent with **Green Fill with Dark Green Text**. **Top/Bottom Rules** > **Bottom 10 %...**. Route 2.4.2.
11. Column R, highlight the above-average values with **Light Red Fill with Dark Red Text**. **Top/Bottom Rules** > **Above Average...**. Route 2.4.2.
12. Column B, put a red border on the international students. **Highlight Cells Rules** > **Text that Contains...**, text `International`, format **Red Border**. Route 2.4.2.
13. Column S, apply the **3 Traffic Lights** icon set. Route 2.4.2.
14. Column T, apply a data bar in any gradient colour. Route 2.4.2.
15. Column U, apply the **Blue - White - Red** colour scale. Route 2.4.2.
16. Go to the `Sparklines` sheet. Select F3 and insert a **Line** sparkline over C3:E3, then fill it down to F32 so every student has one. Route 2.4.1.
17. With the sparkline group selected, switch the type from Line to Column on the **Sparkline** contextual tab.
18. Go to the `Links` sheet. In B2, type `Conditional Formatting Sheet` and link it to that sheet inside this workbook. Route 1.2.3, **Place in This Document**.
19. In B3, type `www.up.edu.mx` and link it to that site. Route 1.2.3, **Existing File or Web Page**.
20. Select the picture in B4 and link it to `https://up4u.up.edu.mx/`. Route 1.2.3, **Existing File or Web Page**. A picture takes a hyperlink the same way a cell does.
21. In B5, type your own email address and link it so that clicking opens a new message to it. Route 1.2.3, **E-mail Address**.
22. Save as `Exercise 3 Excel_Your name.xlsx` and upload it to Moodle.

## Exam routes used here

**1.2.3 Insert and remove hyperlinks.** Select the cell, or click the picture. **Insert** tab, **Links** group, **Link**; older builds and the right-click menu still read `Hyperlink...`. The **Insert Hyperlink** dialog opens with four buttons down the left in the **Link to:** bar: **Existing File or Web Page**, **Place in This Document**, **Create New Document**, **E-mail Address**. Those four are four different dialog faces, and picking the right one is the objective. For a web page, type the target into **Address:**, using **Current Folder**, **Browsed Pages** or **Recent Files** to find it. For a place in this document, pick the sheet under **Cell Reference** and type the cell into **Type the cell reference:**, or pick an entry under **Defined Names**. For an email, fill **E-mail address:** and **Subject:**. Type the visible text into **Text to display:**, and click **ScreenTip...** to set the hover text in the **Set Hyperlink ScreenTip** dialog. Click **OK**. To remove one link, right-click its cell and click **Remove Hyperlink**. For many at once, **Home** > **Editing** > **Clear** > **Clear Hyperlinks** strips the link and keeps the blue underlined look, while **Remove Hyperlinks** strips both. `Ctrl+K` opens the dialog. Typing a URL and pressing `Enter` lets AutoCorrect build the link, which is the short route: no ScreenTip, no display text, nothing demonstrated.

**1.4.3 Freeze worksheet rows and columns.** Excel freezes everything above and everything to the left of the selected cell, so freezing rows 1 to 3 plus columns A and B means the anchor is C4. Click that single cell. **View** tab, **Window** group, **Freeze Panes**, then **Freeze Panes** in the drop-down. **Freeze Top Row** and **Freeze First Column** ignore the selection and freeze one line each. **Unfreeze Panes** releases it. Key tips `Alt, W, F, F`.

**2.1.4 Insert and delete cells.** Select a range of cells, here H13:L13, not whole rows and not whole columns. **Home** tab, **Cells** group, click the **arrow on the Delete button**, then **Delete Cells...**. The **Delete** dialog offers **Shift cells left**, **Shift cells up**, **Entire row**, **Entire column**. Pick **Shift cells up** and click **OK**. Right-clicking the selection and choosing **Delete...** opens the same dialog, which is the route the instruction sheet names. Clicking the face of the Delete button skips the dialog and takes the choice away. `Ctrl+minus` with a partial range selected opens the dialog.

**2.4.1 Insert Sparklines.** Select the cells that will hold the sparklines, one cell per row of data, so F3 for a single row and F3:F32 for the whole group. **Insert** tab, **Sparklines** group. Click **Line**, **Column** or **Win/Loss**. In the **Create Sparklines** dialog, drag over the numbers for **Data Range:**, selecting the data only because headers and totals break the scale. Check that **Location Range:** holds the cells from the first step and has the same number of rows as the data range. Click **OK**. Formatting happens on the **Sparkline** contextual tab, which Office 2019 calls **Sparkline Tools > Design**: the **Show** group carries **High Point**, **Low Point**, **Negative Points**, **First Point**, **Last Point** and **Markers**, the **Style** group carries the gallery plus **Sparkline Color** and **Marker Color**, and the **Group** group carries **Axis**, where **Same for All Sparklines** puts every row on one scale. Without that, each row is scaled to itself and the rows cannot be compared, which is what most tasks are really testing. **Group**, **Ungroup** and **Clear** are in the same group. Changing Line to Column for task 17 is the **Type** group on that same tab. Reach the ribbon with `Alt, N`; the Sparklines group key tips are **TO CONFIRM**.

**2.4.2 Apply built-in conditional formatting.** Select the data cells only. Including the header row is the most common cause of a rule that paints the wrong cells, because a text header counts as smaller than every number. **Home** tab, **Styles** group, **Conditional Formatting**. The menu holds **Highlight Cells Rules**, **Top/Bottom Rules**, **Data Bars**, **Color Scales**, **Icon Sets**, **New Rule...**, **Clear Rules**, **Manage Rules...**. For a threshold, point at **Highlight Cells Rules** and click **Greater Than...**, **Less Than...**, **Between...**, **Equal To...**, **Text that Contains...**, **A Date Occurring...** or **Duplicate Values...**. Type the value in the left box, or click the collapse arrow and point at the cell that holds it, which is what makes the rule follow the data when the number changes. Open the **with** list on the right for **Light Red Fill with Dark Red Text**, **Yellow Fill with Dark Yellow Text**, **Green Fill with Dark Green Text**, **Light Red Fill**, **Red Text**, **Red Border**, **Custom Format...**. For a rank rule, point at **Top/Bottom Rules** and click **Top 10 Items...**, **Top 10 %...**, **Bottom 10 Items...**, **Bottom 10 %...**, **Above Average...** or **Below Average...**; the 10 is an editable spin box. For a graphic rule, point at **Data Bars**, **Color Scales** or **Icon Sets**, hover for live preview, click the variant. **More Rules...** at the bottom of those three galleries opens **New Formatting Rule**. Ribbon keys `Alt, H, L`.

**4.1.1 Insert relative, absolute, and mixed references.** Click the cell, type `=`, then click the cell you want or type its address. It arrives relative, as `N4`. With the insertion point touching the reference, `F4` cycles `N4`, `$N$4`, `N$4`, `$N4` and back. Stop on the form the task needs and press `Enter`. Column O has to read the cell on its left and keep reading the cell on its left as it fills right, so the reference stays relative and no dollar signs go anywhere. Fill in both directions with the fill handle or `Ctrl+R` and `Ctrl+D`, then click a cell in the far corner and read the formula bar to confirm the reference moved the way it should.

**4.2.1 Perform calculations by using the AVERAGE(), MAX(), MIN(), and SUM() functions.** From the ribbon: click N4, go to the **Formulas** tab, **Function Library** group, click the arrow under **AutoSum**, and pick **Average**. Excel writes the function and proposes a range with a moving dashed border; drag over C4:L4 while it is still open if the proposal is wrong, then press `Enter`. Through the dialog: click N4, **Formulas** > **Function Library** > **Insert Function**, open **Or select a category** and pick **Statistical**, select AVERAGE in the **Select a function** list, read the syntax line under it, click **OK**. In **Function Arguments**, click into **Number1** and drag over C4:L4, using the collapse button if the dialog covers the data. Read **Formula result =** at the bottom left before committing, then **OK**. `Alt+=` inserts SUM with a guessed range; `Shift+F3` opens **Insert Function**.

**Expert 2.3.1 Create custom conditional formatting rules.** Select the range first, because the rule is stored against whatever was selected when it was made. **Home** tab, **Styles** group, **Conditional Formatting**, **New Rule...**. The **New Formatting Rule** dialog opens with six entries in **Select a Rule Type**: **Format all cells based on their values**, **Format only cells that contain**, **Format only top or bottom ranked values**, **Format only values that are above or below average**, **Format only unique or duplicate values**, **Use a formula to determine which cells to format**. The **Edit the Rule Description** panel below changes to match. For task 7, pick **Format only cells that contain**, leave the first list on `Cell Value`, open the second list and pick `greater than or equal to`, and type `60` into the box. Click **Format...**, which opens a cut-down Format Cells with four tabs only, **Number**, **Font**, **Border**, **Fill**, because a rule cannot change alignment or protection. Set the font colour on the **Font** tab and then, without closing, set the background on the **Fill** tab, so both land in one operation. Click **OK**, then **OK** again. `Ctrl+1` does nothing inside the rule dialog; the **Format...** button is the only way through.

## Checks

- Row 34 is empty and H13:L13 now holds Sandra Duran Almazán's last five grades. Every student from row 13 to row 33 has ten numbers, none has eleven, and none has five.
- N4 reads `=AVERAGE(C4:L4)` in the formula bar, not a typed number. O4 reads `=N4`. U33 reads `=T33`.
- Scroll right and down. Columns A and B and rows 1 to 3 stay on screen, and a thin solid dark line sits at the C4 corner. The **Freeze Panes** menu now opens with **Unfreeze Panes** as its first entry.
- Change one grade so an average crosses 60, then change it back. Every rule repaints itself instantly. A cell coloured by hand does not move, and that is the single most common way to lose this objective.
- Open **Home** > **Styles** > **Conditional Formatting** > **Manage Rules...** and set **Show formatting rules for** to **This Worksheet**. Nine rules are listed, one per column N to U plus the one on column B, each with the right **Applies to** range and the right **Format** preview.
- Select a cell in column N that the rule painted green and press `Ctrl+1`. Its own **Fill** tab shows no colour, which proves the green is coming from the rule and not from direct formatting.
- Click a sparkline cell. The formula bar is empty, because a sparkline is a cell background and not a cell value, and the **Sparkline** contextual tab appears on the ribbon. A chart object would show selection handles and give you **Chart Design** instead.
- Hover over B2 on the `Links` sheet without clicking. Right-click it and check that **Edit Hyperlink...**, **Open Hyperlink** and **Remove Hyperlink** are all on the menu, which they are only while a real hyperlink object exists on the cell.
- Click the picture in B4. It jumps to the browser rather than selecting the picture, which is the difference between a linked object and a plain one.

## Known problems in the source

- The instruction sheet says the grades are "outdated" and asks for a delete. The Spanish original says they are shifted, which is what the data shows: the block from H14 down sits one row too low. Task 2 above says what is actually wrong.
- The instruction sheet asks for the averages in "columns O through X" and gives the block as `N4:X33`. The sheet stops at column U. The block is `N4:U33` and there are eight answer columns, not eleven.
- The last task of the original puts the email in B3, which is where the website link already went two steps earlier. B5 is the cell with the `Link to email` label next to it.
- The `Status` column reads `Local` and `International` on the `Conditional formatting` sheet and `Local` and `Foráneo` on the `Sparklines` sheet. Same field, two vocabularies, one of them Spanish. The CSV exports keep both as the workbook has them; pick one before the Spanish pass.
- Column D of the grades sheet is headed `Writting`. Column E of the sparklines sheet is headed `3er year`. Both are kept in the CSV so the export matches the workbook.
- The instruction sheet translates the preset menu **Highlight Cells Rules** as "the Rulers option" and calls fills "padding". Both come from running the Spanish original through a translator. The captions above are the ones on the ribbon.
- Cells S3 and T3, in the header row, already carry an icon set and a data bar from whoever built the file. They are demonstrations sitting in the wrong place. Clearing them is harmless.
