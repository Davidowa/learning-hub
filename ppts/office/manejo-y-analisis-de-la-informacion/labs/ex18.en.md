# Exercise 18 · Accessibility, comments and protection

A personnel file of 114 employees, with salaries in it, that has to leave the department without anyone being able to change the numbers or read how the age column was worked out. The real work is four steps: calculate the age, hide and lock that formula, lock the salary column, and protect the sheet. The instruction sheet also teaches the Accessibility Checker and threaded comments on the way past, so the file doubles as the demonstration workbook for both. It lands in week 11, session 22, the second tightest session in the plan, and it is the file COBERTURA names for the range-protection half of Expert 1.2.2. Hand in the protected workbook and the password you used.

**Objectives** MO-200 1.5.4, 2.2.6, 2.3.1, MO-201 1.2.2, 1.2.3, 1.2.5, 3.3.1

## The data

Source workbook `Excel 18.xlsx`, one sheet called `Personnel`. 114 employees in nine columns, A1:I115, with an AutoFilter already applied to the header row. Too long for a table here, so it lives in [data/ex18-personnel.csv](data/ex18-personnel.csv), 114 rows.

## What to do

1. In column J, calculate each employee's age from the date of birth in column I. Give the column a header. Route Expert 3.3.1 for the current date, and the answer is a whole number of completed years, not a decimal and not a date.
2. Protect and hide the formula in column J, so a reader sees the age but the formula bar stays empty when the cell is selected. Route 2.2.6 for the **Protection** tab, then Expert 1.2.2 for the sheet.
3. Protect the Salary cells in column G, so they cannot be edited.
4. Protect the worksheet with a password, leaving everything else editable. Route Expert 1.2.2.
5. Clean the broken defined names out of the workbook before you hand it in. Route 2.3.1. This step is not in the professor's instruction sheet; it is here because the file ships with five names pointing at `Personnel!#REF!` and Name Manager is where you find that out. See "Known problems in the source" below.

6. Run the Accessibility Checker over the sheet and read what it reports. Route 1.5.4. The instruction sheet teaches this tool in its opening pages and then never asks for it, so it is added here.
7. Add a threaded comment on one salary cell explaining why it is locked, then reply to your own comment so the thread has two entries. Route Expert 1.2.5. Use **New Comment**, not **New Note**; they are different objects and the exam grades them separately. Same reason as task 6: the instruction sheet teaches comments and then asks for none.

## Exam routes used here

**Expert 3.3.1 Reference date and time by using the NOW() and TODAY() functions.** Select the cell. **Formulas** tab, **Function Library** group, **Date & Time**, then **TODAY**. The **Function Arguments** dialog opens with no argument boxes at all, only the description and the **Formula result =** line, because the function takes none. Click **OK** and the cell receives `=TODAY()`. For an age, subtract in the formula and then set the result cell to the **General** or **Number** category, never Date, or Excel shows the difference as a date in 1900. `Ctrl+semicolon` stamps a fixed date that never changes again, which looks identical the day you type it and fails any item worded "shows the current date every time the workbook is opened".

For the age itself, `=INT(YEARFRAC(I2,TODAY()))` is the version that stays inside the Function Library, so the whole formula can be built through the dialog: **Date & Time**, **YEARFRAC**, fill **Start_date** and **End_date**, then wrap it in INT from **Math & Trig**. `=DATEDIF(I2,TODAY(),"Y")` returns the same number and has to be typed, because DATEDIF is not listed in any Function Library gallery and Formula AutoComplete does not offer it. Teach YEARFRAC as the graded route and DATEDIF as the one everyone will actually use.

**2.2.6 Apply cell formats from the Format Cells dialog box, Protection tab.** `Ctrl+1`, or the dialog box launcher of the **Font**, **Alignment** or **Number** group on the **Home** tab. Six tabs across the top: **Number**, **Alignment**, **Font**, **Border**, **Fill**, **Protection**. The **Protection** tab holds two check boxes and nothing else, **Locked** and **Hidden**. Both do nothing at all until the sheet is protected, which is the sentence to say out loud in class. **Locked** stops the cell being edited. **Hidden** stops its formula appearing in the formula bar while still showing the result in the cell.

**Expert 1.2.2 Protect worksheets and cell ranges.** The order matters and the first step is the one nobody remembers.

1. Click the **Select All** button at the corner where the row and column headings meet, or press `Ctrl+A`.
2. Press `Ctrl+1`, go to the **Protection** tab, and clear the **Locked** check box. Click **OK**. Nothing visible happens. Every cell in the sheet is now unlocked, which is the opposite of Excel's default.
3. Select only the cells that must stay locked. Here that is column G and column J.
4. Press `Ctrl+1` again. On the **Protection** tab select **Locked**, and for column J select **Hidden** as well. Click **OK**. Both check boxes set in one visit to the dialog.
5. **Review** tab, **Protect** group, **Allow Edit Ranges**. In the **Allow Users to Edit Ranges** dialog click **New...**, type the **Title**, set **Refers to cells**, type a **Range password**, click **OK**, retype it in **Confirm Password**, click **OK**. Click **Permissions...** inside **New Range** if named Windows users should edit without a password at all.
6. Back in **Allow Users to Edit Ranges**, click the **Protect Sheet...** button at the bottom of that dialog. That button is the graded way into the next one, because it proves the two settings belong to a single operation.
7. In **Protect Sheet**, select **Protect worksheet and contents of locked cells** and type a **Password to unprotect sheet**.
8. In the **Allow all users of this worksheet to** list, select what stays permitted: **Select locked cells**, **Select unlocked cells**, **Format cells**, **Format columns**, **Format rows**, **Insert columns**, **Insert rows**, **Insert hyperlinks**, **Delete columns**, **Delete rows**, **Sort**, **Use AutoFilter**, **Use PivotTable and PivotChart**, **Edit objects**, **Edit scenarios**. Clear **Select locked cells** if the locked cells must not even be clicked. This sheet has an AutoFilter on it, so leave **Use AutoFilter** selected or the filter arrows stop working the moment the sheet is protected.
9. Click **OK**, retype the password in **Confirm Password**, click **OK**.

Going straight to **Review** > **Protect Sheet** > **OK** without step 2 freezes every cell in the sheet, because they all started locked. That is the commonest wrong answer to this objective.

**Expert 1.2.3 Protect workbook structure.** **Review** tab, **Protect** group, **Protect Workbook**. The **Protect Structure and Windows** dialog opens. Select the **Structure** check box, type a password in **Password (optional)**, click **OK**, retype it, click **OK**. The same dialog is reached from **File** > **Info** > **Protect Workbook** > **Protect Workbook Structure**, and either entry counts. The **Windows** check box is dimmed on current Microsoft 365 builds, so plan the demonstration around Structure alone. Hiding sheets by right-clicking their tabs is not protection; anyone brings them back with **Unhide** in three clicks.

**1.5.4 Inspect workbooks for issues, Accessibility Checker.** **Review** tab, **Accessibility** group, **Check Accessibility**, or **File** > **Info** > **Check for Issues** > **Check Accessibility**. The **Accessibility** pane opens on the right with **Inspection Results** grouped into **Errors**, **Warnings** and **Tips**. Click an item and Excel selects the offending object; **Additional Information** at the bottom of the pane gives the recommended fix. Select **Keep accessibility checker running while I work** to leave it live. The same objective covers the **Document Inspector** and the **Compatibility Checker**, both under **File** > **Info** > **Check for Issues**, and the exam names them one at a time.

**Expert 1.2.5 Manage comments.** Select the cell. **Review** tab, **Comments** group, **New Comment**. A box opens anchored to the cell; type the text and click the **Post** arrow at its bottom right, or press `Ctrl+Enter`. To answer, click the comment and type in the **Reply** box, then **Post**; the thread growing downward is what makes it a comment rather than a note. To edit your own text, point at the comment, click the **...** button at its top right, and click **Edit comment**. **Resolve thread** greys it out and keeps it; **Delete thread** removes it. Walk the sheet with **Previous Comment** and **Next Comment**, or open **Show Comments** for a pane listing every thread. Notes are the older yellow boxes on their own **Notes** group, with **New Note**, **Edit Note**, **Show All Notes** and **Convert to Comments**. A threaded comment marks the cell with a small purple triangle and its box carries a Reply field; a note marks it with a red triangle and has none. `Shift+F2` inserts or edits a comment on the selected cell.

**2.3.1 Define a named range, and the Name Manager.** **Formulas** tab, **Defined Names** group, **Name Manager**, or `Ctrl+F3`. The list gives every name with its **Value**, its **Refers To**, its **Scope** and its comment. Use **New...**, **Edit...** and **Delete**, and the **Filter** button to cut the list down. A name whose **Refers To** reads `#REF!` is broken and points at cells that no longer exist; deleting it is the only repair. The **Refers to** box at the bottom has its own tick and cross, and nothing is committed until the tick is clicked. Close with **Close**.

## Checks

- Column J shows a whole number for all 114 rows. No `#VALUE!`, no dates in 1900.
- Select any cell in column J. The cell shows the age and the formula bar is empty. If the formula is visible, **Hidden** was never selected or the sheet is not protected.
- Click a salary cell and type. Excel refuses with the message that the cell you are trying to change is on a protected sheet.
- Click any other cell, say a last name, and type. It accepts the edit. If it refuses, step 2 of the protection route was skipped and the whole sheet is frozen.
- Click a cell inside an Allow Edit Range and type. Excel asks for the range password rather than refusing outright. That is the proof the range half took.
- The **Review** tab button now reads **Unprotect Sheet**.
- Open **Name Manager**. No entry reads `#REF!` in its **Refers To** column.
- Run **Check Accessibility** again and read the pane. Note what it still reports; a sheet of plain data with no merged cells and no images normally comes back clean, and knowing that is part of the point.
- The comment cell carries a purple triangle in its top right corner and its box has a **Reply** field. **Review** > **Show Comments** lists the thread. If the pane is empty, a note was inserted instead of a comment.

## Known problems in the source

- The workbook ships with five broken defined names, all pointing at `Personnel!#REF!`: `CRITERIOO`, `CRITERIOY` and `RESULTADOS`, which are visible in Name Manager as workbook-scoped names, plus the two built-in names `Criteria` and `Extract`, which are scoped to the Personnel sheet and appear in the same list. They are the wreckage of an old advanced-filter exercise that this file was cut from. A sixth name, `BD`, still resolves correctly to `Personnel!$A$1:$I$115`. Rather than cleaning them out before class, use them: this is the only place in the pack where a student meets a `#REF!` name in the wild, and Name Manager is the only tool that shows it.
- Column F is headed `Category` and holds office equipment, `Printer`, `Fax` and `Copy Machine`. The actual category is column D, headed `Categoría` in Spanish. Two columns, two languages, one of them mislabelled.
- The dates make the ages wrong in a way that gets worse every year. The youngest date of birth is October 1970 and the oldest is August 1937, so with `TODAY()` the column comes out between 55 and 88, and the entrance dates put everyone at 33 to 48 years of service. The file was built from a 1990s payroll. If the ages have to look plausible, calculate against a fixed reference date in a labelled cell instead of `TODAY()`, and say in class why that trade is being made.
- The instruction sheet says "Protect the Wage cells". The column is headed `Salary`.
- The Format Cells route in the instruction sheet calls the check box "Blocked". The English caption is **Locked**.
- The instruction sheet's title promises accessibility, comments and protection, and its numbered exercise asks for protection only. Tasks 6 and 7 above are added here so the other two get practised on the file that teaches them.
