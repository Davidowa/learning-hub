# Exercise 1 · Cell formats and styles

The first Excel practice of the course. It runs over a small sales table twice, once to format it and once to take it apart, so that every command in the Home tab gets used on data the student can still read at the end. It lands in week 2, session 4, which COBERTURA calls the tightest slot in the plan: half a session of Excel sharing a week with Word, and five objectives added on top of what the syllabus already asks for. Four of those five additions are practised here. Hand in the finished workbook as `Exercise 1 Excel_Your name.xlsx`.

**Objectives** MO-200 2.1.2, 2.1.3, 2.1.4, 2.2.1, 2.2.2, 2.2.3, 2.2.4, 2.2.5, 2.2.6, 2.2.7, 2.2.8

## The data

Two sheets, both named in Spanish in the source file, both holding the same six columns of car sales. `Hoja1` has six models, `Hoja2` has four. Row 1 is the title `Detalle de ventas`, row 2 is the header row, and the data starts on row 3.

Column E holds decimal fractions (`0.03`, not `3%`). It carries no number format yet, which is the point of task 3.

## What to do

1. Select the whole sheet with the Select All button, the small triangle where the row numbers meet the column letters, and set the font to Arial 12 from the **Home** tab, **Font** group.
2. Select columns B, C and D and give them Currency with two decimal places and the `$` symbol, from the **Format Cells** dialog, **Number** tab. Use the dialog, not the ribbon button. Route 2.2.6.
3. Give column E a percentage format with two decimal places from the **Home** tab, **Number** group. Route 2.2.5. This one is the ribbon on purpose, because the exam splits the ribbon route from the dialog route and grades them separately.
4. Select row 2 and wrap the header text, so the long captions run on more than one line. Route 2.2.4.
5. With row 2 still selected, centre the headers horizontally and vertically. Do it in the **Format Cells** dialog, **Alignment** tab, so both settings land as one operation. Route 2.2.2.
6. On `Hoja2`, select A3:F6 and copy it.
7. On `Hoja1`, paste it at A9. The four rows land on rows 9 to 12, directly under the six that were already there.
8. Select the whole of row 8 by clicking its row heading, and copy its formatting onto rows 9 to 12 with **Format Painter**. Four destination rows means a double-click on the brush, not a single click. Route 2.2.3.
9. Insert one sheet column to the left of column A. Route 2.1.3. Everything shifts one column right, so the title that was in A1 now sits in B1.
10. Type `Code` in A2 and `P001` in A3.
11. Fill A4:A12 from A3, so the codes run `P001` to `P010`. Route 2.1.2. Excel reads the trailing digits and increments them.
12. Cut B1 with `Ctrl+X` and paste it into A1 with `Ctrl+V`, so `Detalle de ventas` sits at the left edge of the table again.
13. Select A1:G1 and apply **Merge & Center**, so the title spans the seven columns. Route 2.2.1.
14. Apply the themed cell style **Accent4** to that merged cell. Route 2.2.7. The Spanish gallery reads `Énfasis 4`. The professor's note calls it `Oro Énfasis 4`, after the gold theme colour Accent 4 carries under the Office theme.
15. Select A1:G12 and put all borders on it. The graded route is the **Border** tab of **Format Cells**, where the line style has to be picked before the edges are clicked. Route 2.2.6.
16. Select columns A, B and C and delete them. Route 2.1.3 with whole columns selected. The instructions also name **Delete Cells**, which is route 2.1.4, and with entire columns selected the two produce the same result.
17. On `Hoja2`, select A2:C6 and use **Clear All**. Route 2.2.8. Values, formats and everything else go together.
18. Save as `Exercise 1 Excel_Your name.xlsx` and upload it to Moodle.

Shortcuts worth having in hand before starting: `Ctrl+Z` undo, `Ctrl+C` copy, `Ctrl+V` paste, `Ctrl+X` cut, `Ctrl+1` Format Cells. The instruction sheet gives `Ctrl+G` for save, which is the Spanish binding for Guardar. In an English interface the save key is `Ctrl+S`, and `Ctrl+G` opens the **Go To** dialog instead.

## Exam routes used here

**2.1.2 Fill cells by using Auto Fill.** Type the first value in A3. If the step is not 1, type the second value too and select both. Select the seed cell together with the whole range to be filled, because the selection defines the extent. **Home** tab, **Editing** group, **Fill**. For a straight copy click **Down**, **Right**, **Up** or **Left**. For a pattern click **Series...**, then set **Series in** to **Rows** or **Columns**, **Type** to **Linear**, **Growth**, **Date** or **AutoFill**, the **Step value**, and a **Stop value** if the task gives an end rather than a range. Click **OK**. Dragging the fill handle is the short route: it works, and the **Auto Fill Options** button that appears after a drag is the visible tell that the ribbon was not used. `Ctrl+D` fills down, `Ctrl+R` fills right.

**2.1.3 Insert and delete multiple columns or rows.** Excel inserts exactly as many rows or columns as are selected, so select one whole column heading to insert one column. **Home** tab, **Cells** group, click the **arrow on the Insert button**, not the button face, then **Insert Sheet Columns**. To delete, select the whole columns, click the **arrow on the Delete button**, then **Delete Sheet Columns**. Clicking the face of the Insert button runs **Insert Cells** with a silent shift instead, which is a different objective and can tear the grid apart. `Ctrl+Shift+plus` inserts, `Ctrl+minus` deletes.

**2.1.4 Insert and delete cells.** Select a range of cells, not whole rows and not whole columns. That is what separates this from 2.1.3. **Home** tab, **Cells** group, arrow on the **Delete** button, **Delete Cells...**. In the **Delete** dialog pick **Shift cells left**, **Shift cells up**, **Entire row** or **Entire column**, then **OK**. The dialog has to appear and a direction has to be chosen in it.

**2.2.1 Merge and unmerge cells.** Select A1:G1. Only the top left cell keeps its value. **Home** tab, **Alignment** group, click the **arrow on Merge & Center**, not the button face, and pick **Merge & Center**, **Merge Across** or **Merge Cells**. Read the warning about the discarded values before clicking **OK**. To unmerge, same arrow, **Unmerge Cells**. The dialog route, which combines with 2.2.6: `Ctrl+1`, **Alignment** tab, **Merge cells** check box in the **Text control** section. Ribbon keys **Alt, H, M, C**.

**2.2.2 Modify cell alignment, orientation, and indentation.** `Ctrl+1`, or **Home** tab, **Alignment** group, dialog box launcher. **Format Cells** opens on the **Alignment** tab. In **Text alignment**, open **Horizontal** and pick from **General**, **Left (Indent)**, **Center**, **Right (Indent)**, **Fill**, **Justify**, **Center Across Selection**, **Distributed (Indent)**. Open **Vertical** and pick from **Top**, **Center**, **Bottom**, **Justify**, **Distributed**. Set **Indent** after Horizontal, because the spin box only enables for the indent variants. Set the angle in **Orientation** by dragging the red diamond on the half dial or typing into **Degrees**. Click **OK** once and all of it lands as one operation. The ribbon buttons are one operation each, with one undo step each.

![Format Cells, the Alignment tab](../../../img/en/format-cells-alignment.png)

*Horizontal and Vertical sit one above the other, which is what lets task 5 centre the headers both ways and click OK once. Both lists still read their untouched defaults here, General and Bottom, so this is the tab as it opens rather than the tab as task 5 leaves it; Indent sits beside Horizontal because it belongs to the indent entries in that list.*

**2.2.3 Format cells by using Format Painter.** Select the source, here the whole of row 8. **Home** tab, **Clipboard** group, **Format Painter**. A single click arms the brush for one destination and then releases it. Rows 9 to 12 are four destinations, so **double-click** Format Painter, drag over each row heading in turn, then press `Esc` to release. The double-click is the part the exam watches for whenever more than one target area is named. Ribbon keys **Alt, H, F, P**. There is no Ctrl combination for it in Excel.

**2.2.4 Wrap text within cells.** Select row 2. `Ctrl+1`, **Alignment** tab, **Text control** section, select the **Wrap text** check box, and set **Vertical** or **Horizontal** in the same visit if the task pairs them. Click **OK**. **Shrink to fit** and **Wrap text** clear each other, so a task that says "make it fit without changing the row height" wants Shrink to fit. The ribbon button at **Home** > **Alignment** > **Wrap Text** is the short route, `Alt, H, W` by key tips.

**2.2.5 Apply number formats.** This objective is the ribbon one on purpose. Select the numbers only, not the header. **Home** tab, **Number** group. Open the **Number Format** list at the top of the group and pick **General**, **Number**, **Currency**, **Accounting**, **Short Date**, **Long Date**, **Time**, **Percentage**, **Fraction**, **Scientific** or **Text**. Adjust with **Accounting Number Format** and its arrow, **Percent Style**, **Comma Style**, **Increase Decimal**, **Decrease Decimal**. For column E, Percentage plus two clicks of **Increase Decimal**. Typing `3%` into a cell that already holds `3` turns the value into 0.03 and every formula downstream changes with it, which is why the format is applied rather than the number retyped. The `Ctrl+Shift` number-row shortcuts are bound to the shifted symbol rather than the digit, so on a Latin American keyboard the physical keys differ. **TO CONFIRM** on the lab machines before teaching them as digits.

**2.2.6 Apply cell formats from the Format Cells dialog box.** `Ctrl+1`, or the dialog box launcher of the **Font**, **Alignment** or **Number** group on the **Home** tab, all three of which open the same dialog on a different tab. Six tabs across the top: **Number**, **Alignment**, **Font**, **Border**, **Fill**, **Protection**. For task 2, go to the **Number** tab, pick **Currency** in the **Category** list, set **Decimal places** to 2 and **Symbol** to `$`. For task 15, go to the **Border** tab and mind the order, because this is the most common way to lose the item: choose the **Style** from the Line box and the **Color** from the Color list **first**, then click a **Presets** button (**None**, **Outline**, **Inside**) or click the individual edges in the preview box. A border drawn before the style is set comes out in the previous style, and clicking the style afterwards does nothing to it. Click **OK** once. `Ctrl+1` opens the dialog on whichever tab was last used, `Ctrl+Shift+F` opens it on **Font**, and `Ctrl+Tab` walks the tabs.

![Format Cells, the Number tab](../../../img/en/format-cells-dialog.png)

*The tab task 2 lands on, with the six tab names of the whole objective across the top. Category reads General in this shot, which is why the right side holds nothing but Sample; picking Currency in that list is what brings out the Decimal places and Symbol boxes.*

![Format Cells, the Border tab](../../../img/en/format-cells-border.png)

*Style and Color are on the left of the tab, the three Presets and the eight edge buttons on the right. Everything on the right draws with whatever is selected on the left at that moment, which is the order task 15 turns on.*

**2.2.7 Apply cell styles.** Select the merged title cell. **Home** tab, **Styles** group, **Cell Styles**. The gallery opens in sections: **Good, Bad and Neutral**, **Data and Model**, **Titles and Headings**, **Themed Cell Styles**, **Number Format**. Accent4 sits under **Themed Cell Styles**. Hover to live-preview, then click. Reproducing the look by hand with font and fill attaches no style, so it will not follow a theme change and it demonstrates nothing. Ribbon keys **Alt, H, J**. `Alt+'` opens the **Style** dialog directly.

**2.2.8 Clear cell formatting.** Select A2:C6 on `Hoja2`. **Home** tab, **Editing** group, click **Clear**, the eraser icon on the right of the group. The menu offers **Clear All**, **Clear Formats**, **Clear Contents**, **Clear Comments and Notes**, **Clear Hyperlinks**, **Remove Hyperlinks**. This task wants **Clear All**, which empties the cells of values, formats, comments and conditional formatting together. **Clear Formats** keeps the values, **Clear Contents** keeps the formats, and the two sit next to each other on the same short menu. Pressing `Delete` runs Clear Contents, so it does not answer this objective. Ribbon keys **Alt, H, E, A**.

## Checks

- `Hoja1` reads Arial 12 everywhere. Click any cell and read the **Font** box.
- Reselect a currency column, press `Ctrl+1` and look at the **Number** tab: **Currency**, 2 decimal places, `$` symbol.
- The percentage column shows two decimals and the formula bar still reads the raw fraction. That split proves the number was formatted and not retyped.
- Row 2 is taller than the rest and the header captions run on two lines. Click a header and read the formula bar: the string has to be one continuous line. If it is broken across two lines someone pressed `Alt+Enter`, which looks like wrapping and is not.
- Rows 9 to 12 carry row 8's fill, font and borders while keeping their own values.
- The codes run `P001` to `P010` down column A before task 16 removes them.
- The title cell shows one address in the **Name Box**, `A1` and not `A1:G1`, and **Merge & Center** shows as highlighted on the ribbon while it is selected. Open **Cell Styles** and Accent4 is boxed in the gallery.
- After task 16 the sheet starts with what used to be `Precio de venta`, the merged title has shrunk to A1:D1, and no cell reads `#REF!`.
- On `Hoja2`, A2:C6 is empty and unformatted. If the values went but a fill or a border stayed, **Clear Contents** was clicked instead of **Clear All**.

## Known problems in the source

- Task 16 deletes three columns of the table that the previous fifteen tasks formatted, and the instructions never say whether the file handed in keeps the deletion or undoes it. Read as written, it stays deleted. Settle this with the professor before grading.
- The instruction sheet lists `Ctrl + G` as save. That is the Spanish binding, Guardar. In an English interface `Ctrl+G` opens **Go To**.
- The style is named `Oro Énfasis 4`, which mixes the gold theme-colour caption with the gallery entry. The gallery entry is **Accent4**, `Énfasis 4` in Spanish.
- The workbook title cell reads `Detalle de ventas` in sentence case. The instructions quote it as `Detalle de Ventas`.
- The sheets are still called `Hoja1` and `Hoja2`, and the column headers are still Spanish, in a course that is otherwise English first. Renaming them would break the step references in this file, so they are left alone here and flagged for the Spanish pass.
