Latest releases are observations, not a compatible dependency set. Use the Expo SDK's bundled dependency mapping for the React Native track and commit the resolved lock file in the class starter. Do not independently upgrade React or React Native inside that SDK. This repository does not install or activate Expo.

The inspected Expo 57.0.28 package mapping specifies React 19.2.3 and React Native 0.86.3, rather than the independent latest versions above. Its examples use the versioned Expo 57 APIs. This mapping is a starting compatibility constraint; the class starter still needs a lock file and an actual build. Source: the `bundledNativeModules.json` shipped in the official npm Expo package, https://registry.npmjs.org/expo/57.0.28.

React Native documentation: https://reactnative.dev/docs/getting-started

Expo versioned APIs: https://docs.expo.dev/versions/latest/

SwiftUI documentation: https://developer.apple.com/documentation/swiftui

Xcode system requirements: https://developer.apple.com/xcode/system-requirements

The SwiftUI track requires the Mac and Xcode combination supported by the selected release. Device signing, beta distribution and store submission have separate requirements; consult the current vendor instructions before assigning a distribution task. No account purchase or public store submission is required by these slide examples.

The samples are excerpts. Parsing checks do not validate the complete app, device permissions, signing or store acceptance. The course includes those checks as explicit lab evidence.
