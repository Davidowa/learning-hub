Topic: Punteros y cadenas de caracteres
Action title: char* apunta a un carácter de la cadena
Subtitle: El arreglo guarda caracteres; el puntero permite acceder a ellos.

FIRST SECTION, broad main diagram:
char matricula[12] = "123456";
char* ptr = matricula;
Code caption: En esta inicialización, matricula se convierte en un puntero a su primer elemento: ptr == &matricula[0]. El arreglo y el puntero son objetos distintos.
Diagram show contiguous array cells indices 0,1,2,3,4,5,6 with contents '1','2','3','4','5','6','\0'. Label remaining five cells 'Índices 7 a 11: también contienen \'\0\''; visually show these five small cells or one grouped extension clearly NOT a single array cell. ptr arrow points specifically to index 0, label 'Dirección ilustrativa: 0x2000'.
Caption: \0 es el carácter nulo y marca el final de la cadena. El arreglo tiene 12 elementos; 6 guardan dígitos y los otros 6 se inicializan en cero.

READING A char*:
std::cout << ptr;    // 123456
std::cout << *ptr;   // 1
std::cout << static_cast<const void*>(ptr);
Caption: cout trata char* como una cadena y lee hasta \0. *ptr es solo el primer carácter. La conversión a const void* permite mostrar la dirección.

GETTER WITH NO ARRAY COPY:
class Estudiante {
    char matricula[12] = "123456";
public:
    const char* getMatricula() const;
};
const char* Estudiante::getMatricula() const {
    return matricula;
}
Diagram: object Estudiante outline enclosing its matricula array; outside small pointer p with arrow TO first cell INSIDE object. Direction must be from returned pointer to existing array, never from array to a copied array. Label 'Se devuelve un puntero al primer carácter; no se copia el arreglo.'

USE:
Estudiante e;
const char* p = e.getMatricula();
std::cout << p;     // 123456
std::cout << *p;    // 1

TWO const qualifiers, short labels using the getter signature above:
const char* impide modificar los caracteres mediante el puntero devuelto.
El const después de () indica un método que no modifica el estado del objeto.

LIFETIME AND SAFETY orange strip:
El puntero devuelto puede usarse mientras e exista y su almacenamiento siga siendo válido. Al destruir e, p queda colgante. Antes de imprimir una cadena, debe existir un \0 accesible dentro del almacenamiento válido.

FINAL QUICK REVIEW, small integrated line:
&x obtiene una dirección · p la guarda · *p accede al objeto · char* con cout imprime la cadena hasta \0.
