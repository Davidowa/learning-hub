Topic: Punteros: dirección y contenido
Action title: Un puntero guarda una dirección
Subtitle: & obtiene la dirección; * permite acceder al objeto apuntado.

MAIN VISUAL, use upper third of page:
Code:
int edad = 20;
int* ptr = &edad;
Diagram: box ptr has '0x1000', arrow from this box TO box edad containing '20'; below edad label '&edad = 0x1000'. Label arrow 'apunta a edad'. Show that ptr itself is a separate variable; do not label ptr's own address 0x1000.
Caption: edad guarda 20; ptr guarda la dirección de edad. Las direcciones de esta lámina son ilustrativas.

FOUR EXPRESSIONS table, with columns Expresión / Qué pide / En este ejemplo
edad / El valor de edad / 20
&edad / La dirección de edad / 0x1000
ptr / La dirección guardada / 0x1000
*ptr / El valor del objeto apuntado / 20
Below: Después de inicializar ptr: ptr == &edad y *ptr == edad.

TWO SENSES OF *: two small adjacent examples with labels
int* ptr = &edad;
Al declarar, * indica que ptr es un puntero a int.
*ptr = 25;
En una expresión, *ptr designa a edad: permite leerla o modificarla.
Small before-after diagram: edad 20 -> execute '*ptr = 25;' -> edad 25. ptr keeps 0x1000. Arrow connects same variable before/after. Caption: Cambia edad; la dirección guardada en ptr se conserva.

FULL RUNNABLE EXAMPLE, compact code block, exactly:
#include <iostream>
int main() {
    int edad = 20;
    int* ptr = &edad;
    std::cout << edad << '\n';
    std::cout << &edad << '\n';
    std::cout << ptr << '\n';
    std::cout << *ptr << '\n';
    *ptr = 25;
    std::cout << edad << '\n';
}
Adjacent output annotation, not another full code block: '20 · dirección de edad · la misma dirección · 20 · 25'. Do not print the illustrative address as a guaranteed output.

ANALOGY, one small explanatory strip, no house illustration needed:
Como una casa: edad es el contenido; &edad es la dirección; ptr es la nota con esa dirección; *ptr permite acceder al contenido.

CAUTION, restrained orange:
Un puntero debe apuntar a un objeto válido para leer o escribir mediante *. No desreferencies nullptr ni un puntero sin inicializar.
Source note: C++20: [expr.unary.op], [dcl.ptr].
