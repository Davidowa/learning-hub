# Learning Hub · C++20 · Infografías para P3

Las ocho hojas están numeradas por tema. Cada una está disponible como PDF carta y como imagen PNG con el mismo nombre. El archivo `P3 - CPP - Infografías completas - Carta.pdf` reúne las ocho páginas para consultar o imprimir la serie completa. Para imprimir, usa papel carta y tamaño real.

La carpeta lectura contiene el texto de consulta y la carpeta ejemplos contiene programas completos de C++20. Los bloques de las infografías son fragmentos didácticos; cada archivo de ejemplos es un programa independiente con sus bibliotecas y su función main.

Puedes compilar un ejemplo con clang++ o g++ y la opción `-std=c++20`. Por ejemplo, desde esta carpeta:

```sh
clang++ -std=c++20 ejemplos/07-funciones-virtuales-y-override.cpp -o virtuales
```

Después ejecuta `./virtuales`. La salida esperada es 78.54. El ejemplo 08 imprime 78.54, 24.00 y 9.00 en ese orden.

«Nombres para Blackboard.csv» contiene el orden, el tema y el nombre para mostrar de cada archivo. Para compartir una sola versión por tema, selecciona el PDF; el PNG permite mostrar la misma lámina como imagen.
