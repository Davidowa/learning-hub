# MOS Certification

Practice projects for the Microsoft Office Specialist certification: Excel Associate, in Spanish. There are 1,201 numbered projects, P001 to P1201, split across six compressed files. Each project comes with the starting workbook, the step-by-step guide in PDF, and the solved workbook. Each file also includes the project index and the guide with glossary; the last three also carry two infographics, one on lookup functions and one on pivot tables.

## Series

| Range | Series | Projects |
| :- | :- | -: |

| P502–P801 | Certification, series 2 (same format as P001–P301) | 300 |
| P802–P1201 | Certification, series 3 (same format; 100 new businesses) | 400 |
