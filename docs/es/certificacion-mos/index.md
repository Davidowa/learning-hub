# Certificación MOS

Proyectos de práctica para la certificación Microsoft Office Specialist: Excel Associate, en español. Son 1,201 proyectos numerados de P001 a P1201, repartidos en seis archivos comprimidos. Cada proyecto trae el libro de inicio, el paso a paso en PDF y el libro resuelto. Cada archivo incluye además el índice de proyectos y la guía con glosario; los tres últimos traen también dos infografías, una de funciones de búsqueda y otra de tablas dinámicas.

## Series

| Rango | Serie | Proyectos |
| :- | :- | -: |
| P001–P301 | Certificación (estilo MOS, 5 dominios) | 301 |
| P302–P321 | Curso: solo temas del curso (3, 4, 5, 6, 7, 8, 11) | 20 |
| P322–P501 | Mixto: tareas del examen + 2 o 3 del curso | 180 |
| P502–P801 | Certificación, serie 2 (mismo formato que P001–P301) | 300 |
| P802–P1201 | Certificación, serie 3 (mismo formato; 100 negocios nuevos) | 400 |
